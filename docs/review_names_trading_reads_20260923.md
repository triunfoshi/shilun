# 题材名称与交易页面读取修复 · 2026-09-23

## 根因和处理

1. 东方财富统一成分使用 `name`，前后排证据生成仍只读旧字段 `con_name`。证券资料里存在 `000017.SZ / 深中华A`，但近7日没有涨停记录的成分因此显示代码。
   - 新生成名单同时兼容 `name` 和 `con_name`。
   - 读取旧主快照、展开题材明细时，按缺名证券批量查询证券资料，仅补空名称或代码占位；保留历史有效名称、角色和行情，不重算也不写回复盘事实。
2. 交易页通过 ECS Mongo 隧道读取，原3秒超时偏短；每次请求还重复初始化全部索引。
   - 20个只读接口跳过索引初始化，连接预算调整为15秒、单次读取30秒；写入入口继续初始化索引。
   - 驱动异常返回可读的503 JSON，隐藏底层连接信息；写请求异常提示先核对是否已保存，避免盲目重复提交。
3. 交易页读取超出需求的研究与回放档案。
   - 选品/板块监控仅取身份、门槛及样本成员；持仓板块参考只取状态及收益字段。
   - 工作台按允许股票筛选历史事件，只取展示字段，完整审计证据保留在原档案。
   - 成交台账在数据库端筛选、排序和限制条数，只查询缺名成交对应的证券名称。
