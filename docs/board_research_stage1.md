# 首板分析与打板效应：第一批实施

状态：两页及统计/研究接口已实现；真实模型服务返回 HTTP 503，AI 真实生成验收尚未完成。基准：本地 Vibe-AStock `d7a0e568424f5c0b1de9e39b1ddd733ecdbf9edb`，遵循 Apache-2.0 归属声明。

## 本批交付

- 首板分析：首板清单、首次封板时间、炸板次数、价格、涨幅、成交额、流通市值、原因、行业；单股与批量 AI 分析、停止、重试及研究记录。
- 打板效应：Vibe 七组、最后封板时间分组、情绪分组、覆盖与结构变化；20/30 交易日窗口、最近7日与此前区间对比、每日均值/中位数与7日滚动线；增加最高板和炸板反馈。
- 原生 HTML/CSS/JS 与 FastAPI；共享数据适配、统计及 AI 服务，不运行另一套 Vibe 后端。

## 指标契约

1. 反馈日 T 使用 T-1 形成的固定名单；按真实交易日历配对。最高板来自 T-1 完整涨停池，不能由 T 日幸存名单重选；股票池和制度范围明确展示。
2. 原版高标重命名“三板及以上”，仍使用 T-1 连板数 >=3；“最高板”单列相对地位。连板指连续封板，不能用N天M板代替。
3. 封板组为收盘涨停；炸板组为盘中触及涨停且收盘未封住；炸开又回封仍在封板组。按股票与日期去重。
4. 主要收益为 T收盘/T-1收盘-1；另列开盘溢价、开盘后收益，以及炸板日涨停价至次日收盘的理论价格损益。后一项不是实际成交回测。
5. 统计单位为股票日。均值、中位数、胜率由原始样本汇总，滚动中位数不取每日中位数的平均。最近7日用日历最后7个交易日，不跳过缺失日。无样本/缺数据为null，不能显示零。
6. 默认30日，同时比较最近7日与此前23日；20日比较最近7日与此前13日。每组保留样本数、独立股票数、有效日期、缺失日期。
7. 首板表展示首次封板；早封组依据最后封板<=10:00；尾盘组>=14:30。原版情绪是窗口内回顾性三分位，不能当作当时可执行规则。
8. 原版全样本保留一字股；一字主导补涨不参与，打开一字不自动变成换手确认。未知形态不得标成可参与。
9. 历史原因与题材只能来自对应日期的证据；行业不可冒充题材。全局汇总去重，多题材明细允许重叠但须注明。
10. 部分覆盖显示实际日期及覆盖数。数据源、数据所属日期、采集时间和规则版本可核验；刷新失败保留上一份同查询有效结果，不能把别的窗口或日期显示为当前结果。

## 功能归属与迁移清单

|能力|归属|本批处理|
|---|---|---|
|涨停/炸板/昨日涨停原始证据|现有 review 数据层|复用 dated_pools、sources 与 Mongo 数据，补齐必要归档|
|群体统计与滚动汇总|board_effects|纯计算单一入口，供页面和后续总览引用|
|首板清单|首板分析|与打板效应共用股票标识、价格、日期及形态口径|
|单股详情|既有个股研究|带日期跳转，不另建个股分析引擎|
|AI深入分析|共用研究服务|使用配置的模型，基于有日期的公开市场证据，不改写指标|
|指数复盘/大盘研究|后续市场全景|本批不删除；待所有调用方完成迁移再退役重复实现|
|短线题材/板块研究|后续方向与核心|本批不删除；之后统一角色、持续性与题材分组|

## 实施结果与边界（2026-09-14）

- 研究区新增“首板分析”“打板效应”；沿用既有导航、日期控件、个股详情及设计变量。共用 `board_data`、`board_effects`、`research_ai`，未引入 React、LangChain 或另一套 Vibe 服务。
- 首板页提供对应日期名单、逐股/顺序批量研究、停止、重新分析、已完成记录恢复，以及 Markdown 保存。研究当前只使用表内证据，明确标注新闻未检索。
- 真实模型配置沿用本机已有 Vibe 配置；两次真实请求均返回 HTTP 503。完成、异常、中断与取消路径已用独立流式响应验证，不能据此称真实生成已通过。
- 新的日线读取选项保留源站 `pre_close`，用于除权参考价口径；原有调用保持原列契约。涨跌停价源部分日期的 `pre_close` 全空，不能用涨停价反推昨收，也不拿昨日未复权价格强补。
- 只查询/补齐当日及前日名单所需股票的价格，复用原数据存储和行情客户端。全市场日线任务仍由现有同步模块负责。
- 历史 U/Z 来源按记录日期与类型核验；东财过期接口的日期回退被拒绝。空历史列表无法独立验证时标缺失。历史 Tushare 范围为沪深非ST，与东财原始范围可能不同，来源保留到日期。
- 页面上的样本是股票日；价格不齐会在卡片顶部单独提示，并保留未取得价格的原始成员。样本明细按50条分页，日趋势不跨缺口连线。

### 与截图的可验证差异

冻结同一批 Vibe 原始数据后，首板 1077 条，均值 +0.73%、中位数 -0.36%、胜率 47.4%、超额 -0.37%，与原版一致。还原原版时间处理时，七组整体、情绪分组和封板时间曲线全部通过对照。

原版把三条 `000000` 当作有效早封。生产版本将它们归为“封板时间未知”：同一冻结样本的早封从359条变为356条，均值 +1.27%、中位数 +0.51%，页面明确说明。因此没有把错误时间原样复刻。新增历史来源补足窗口后，实时页面的样本也会比截图更多，不能直接用截图数字判定新的30日全窗口结果。
