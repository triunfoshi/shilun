# 交易复盘界面精简

用户反馈：不知道从哪里开始复盘，工具入口和完整档案同时展开，阅读负担太大。

改造后的默认路径：

1. 首页点击“开始复盘”。
2. 选择一轮交易；可按股票查找，日期和状态筛选按需展开。
3. 查看并补充当时理由、预期、仓位与退出条件。
4. 下一步核对预期是否达到、仓位和卖点是否按计划、真实收益与规则参考。

首页和三步流程之外的功能集中在更多工具：模式卡、统计、买前预案、导入对账、观察样本、当前账户工具、来源归档及历史研究。完整档案和技术字段均保留，不删除记录或改变收益计算。

本轮仅调整页面结构、交互和文案，复用现有版本化补记、回证及统计所有者。旧预期和模式版本、未知值、事后补记性质以及原始结构化规则继续保留。
