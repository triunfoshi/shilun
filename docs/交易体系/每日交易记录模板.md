日期：

适用于下一笔真实交易。系统可自动保存的行情、梯队、成交和盈亏不要求手抄；尚未接入自动保存时，以原始文件或带时间的记录留存。没填到的内容标未知，不能事后假装当时已经知道。

## 决定前的五项记录

| 项目 | 填写 |
|---|---|
| 交易模式和具体触发 | 我做的是……；只有出现……才买；当前已确认／未确认 |
| 主板块和观察参照 | 所属主板块……；我在看……；选择它而不选其他票的原因…… |
| 预期和验证时点 | 到……时点，应出现……；弱于预期时…… |
| 失效和退出 | 出现……说明原逻辑失效；准备如何处理…… |
| 仓位与风险 | 计划金额／股数……；最大允许亏损……；允许加仓的前提…… |

记录时间：  
描述的决策时间：  
记录性质：事前／成交后补记／记不清。

可以先只留一句话：**我做什么模式，看到什么才买，参照谁，预期何时验证，什么情况退出，最多承担多少风险。**

## 环境与观察

- 大盘：指数位置与方向、量能是实际还是估计、量能流向、市场广度。
- 板块：当日阶段、核心与跟随、同类买入后的反馈。
- 情绪与梯队：强股溢价、失败股反馈、高标状态、各高度名单与晋级分母。
- 观察名单：看过哪些、何时加入、买了谁、没有买谁以及原因。
- 反向证据：目前有什么事实与我的判断不一致。

这些记录分别注明时点和证据来源。盘后完整结果另记，不能放回上午的决策理由。

## 收盘或清仓后

- 实际发生了什么，与原预期相比如何：
- 有没有偏离原计划，在哪个时点：
- 如果亏损，是正常风险兑现，还是入场、持有、卖出、仓位或信息出了问题：
- 能支持这个归因的原始证据：
- 哪些仍无法判断：
- 如果这笔最后赚钱，我是否仍认为过程有问题：
- 如果这笔最后亏钱，我是否仍认可原来的交易逻辑：
- 待检验假设和下一次要记录的条件：

实际盈亏由真实成交核算。卖后上涨、盘中出现过更高价，都只先记为事实，不能直接当成卖点错误或可赚到的利润。
