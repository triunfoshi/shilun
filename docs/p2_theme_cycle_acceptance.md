## 本轮修正

- 当日价格上下限无覆盖，不能由空集合推导出零跌停；已知零跌停时高/中/低/未知均为 0，集中度不适用。
- 昨日涨停反馈沿用 Vibe-AStock `duanxian/backtest.py` 的单日全体涨停样本：昨日收盘涨停股 → 今日收盘涨跌幅中位数。只统计有效价格；同时显示有效数/总样本，覆盖不足 80% 不发布统计。
- 东方财富历史请求必须校验 `qdate`。2026-09-09 历史请求实际返回 `qdate=20260911` 与空池，不能当成零。
- Vibe 本地定稿缓存是可选迁移输入：默认 `~/.duanxian-agents/cache/prev_pool`，可用 `SHILUN_VIBE_CACHE_DIR` 指定。只在生成复盘时写入 `review_previous_limit_pools`；记录校验值、数据日、样本日与来源，并用目标日日线交叉核验。页面读取不依赖 Vibe 服务运行。
- 生成复盘时先核验交易日历，再补最近 21 个交易日缺失的整日日线与涨跌停价；使用现有 Tushare `daily` / `stk_limit`，不以固定 10% 等涨幅猜测涨跌停。明确提供的零价格下界与缺失值分开处理。涨停数沿用东方财富板池，跌停数为本地全市场日线核验（含 ST），两个来源的筛选范围分别披露。

## 题材证据

默认展示前三个并行方向，其余折叠。每条方向都带独立前排承接。行业字段不足以证明题材，明确标记“行业线索 · 待题材交叉验证”，不显示虚构主线。

7日是日历中的7个交易日，不是最近7个有板池的日期。存在性条件可由窗口内真实证据通过；缺日时无法证明“不存在”。成交额按相同的全行业成员比较；没有真实板块全体成员时，固定7日样本只能作为代理，不能冒充板块。

前排固定为昨日该方向最高板与下一档（存在连板时最低2板），后排为剩余昨日涨停股。保留今天断板、下跌的样本；新首板不倒灌进昨日队列。前排收益、后排收益、收益差（百分点）、高低价差、收盘区间位置、成交量较昨倍数、开板次数和最后封板时间分开呈现。高低价差不是按分钟顺序计算的最大回撤，成交量较昨不是行情软件的盘中量比。

一字板单列为“封死·换手未验证”，不算弱承接，也不宣称可成交。价格承接率只以有日线且非一字的前排为分母，显示覆盖与缺失。该指标不是资金主体、分钟回封速度或买入信号。
