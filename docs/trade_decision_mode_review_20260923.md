# 明日预案验收：模式比较与蟹老板的切换依据

2026-09-23。范围为明日预案验收；今日跟踪的数据接入继续暂缓。9月21日预案仍只用截至当日的行情，以下9月22日回复仅用于历史研究，不回填预案。

## 结论

应将三行收益理解为**不同阶段样本的反馈**，不能直接据此评选“最好的交易模式”。当前系统将近期收益最高的一组选成优先模式，这一做法已取消。历史中位数、红K频率和换手事实保留，不人为惩罚核心组，也不降低其真实历史收益。

蟹老板更稳定的思路可以归纳为：**先看环境与资金实际去向，再看各玩法昨日参与者的反馈，最后看自己能否在当前节点参与。** 首板、连板、抱团可以并存；旧玩法失效不保证替代玩法成立，必要时等待。此句为跨文归纳，不是作者原有公式。

“成为核心以后通常继续上涨”不能直接当作前提。核心资格代表过去已强，未来仍可能失败。2025年2月20日他明确说，趋势卖点可能同时是抱团的激进买点，而风险是次日跌停；21日10:02又说短暂抱团结束、选择空仓。9月14日至15日也有看好穿越后承认失败的连续记录。

## 1. 为什么现在的横向比较不公平

|当前组|入组条件与时点|它能说明什么|不能据此推出什么|
|---|---|---|---|
|首板|当日首次涨停；目前是全市场首板研究人口，并非已经执行MA5的交易|首板先手的开盘溢价、后续群体延续|所有首板都能买到，或这些收益就是MA5收益|
|连板|本轮首次达到三板|达到该晋级阶段后的反馈，包含后来断板者|代表一进二等所有接力阶段，或全部是可参与的换手板|
|抱团观察·短线核心|先经历三连板、一定窗口至少五次涨停等独立资格筛选|当时已取得资格的强势样本后续反馈|所有样本都属于同一种抱团模式，或该收益来自可复制的买卖规则|

主要偏差有六项：

1. **条件筛选不同。** 核心已通过更强的历史表现筛选，全量首板混有大量普通启动。它们不是同一阶段的三个平行实验组。
2. **角色有重叠。** 同一股可以先首板、再连板、最后成为核心；作者也会把某只股票同时按趋势或抱团理解。三组不能相加成组合收益，也不是互斥的三种风格。
3. **进入时点与可赚区间不同。** T收盘确认资格后，不能自动假设可以按T收盘买入。“次日开盘反馈”是先手的反馈；次日新买已经付出了这段溢价。
4. **日历与样本权重不同。** 1076个首板事件、56个三板事件、19个核心事件，覆盖的具体日期和市场状态并不相同；T+5有效样本分别779、42、15。中位数减少极端值影响，不会消除选择条件与样本量差异。
5. **人口口径不同。** 当前首板/三板人口含ST，核心资格剔除ST；成交额档也只筛首板一行。涨跌幅限制、流动性和容量分布都可能不同。
6. **每天更新的核心名单仍是条件样本。** 使用昨日名单能避免用今天赢家计算今天反馈，但每天资格更新不等于某个买入后持续持有的组合；相同日历轴也不代表公平策略比较。

现有核心历史不是用今天仍活跃的核心回填全部过去：它按历史前缀重建，并保留失效后的事件收益。这减少了幸存者偏差，但不消除以上可比性问题，也不等于严格事前回测。

因此，本轮没有重写收益，也没有用“核心组收益打折”等任意修正。页面明确各组条件，移除跨组排名及“累计收益高所以应该换模式”的暗示。若以后比较策略效率，应在同一市场状态、同一可进入时点、相同期限与成本/可成交规则下进行；这属于之后的研究，不在此次验收中假装已经完成。

## 3. 对三类玩法应如何分别判断

下表为原文蒸馏后的研究建议，不是作者已有量化公式，也不是本轮新增执行策略。

|观察玩法|偏向它的场景|重点正反馈|重要反证|
|---|---|---|---|
|容量首板套利|指数企稳或放量向上，目标板块有主动前排，资金愿意承接相应容量；有时也来自接力退化后的低阻力选择|昨日同类首板开盘溢价、正溢价广度、开盘后保持，目标板块和容量参照的主动性|昨日首板普遍低开/冲高回落、指数右侧失败、资金未流向目标板块、放量无人接|
|连板接力|换手梯队晋级有持续性、分歧后能再加强、失败者不被普遍核死|可换手高标和同梯队次日反馈、断板退场质量、前后排带动|只剩买不到的一字高度，可换手票连续亏损，断板跌停和流动性枯竭|
|核心抱团|广泛题材轮动或机会减少，少数既有辨识度核心在分歧中仍得到资金聚焦|昨日固定核心名单的反馈、该弱不弱后的主动修复、真实换手，以及其他核心是否同步恶化|核心/跟随者持续失去承接，缩量加速后开板无人接，顺指数方向分流且旧核心自身也转弱|
|等待|候选玩法都没有支持，或虽有持仓行情但没有适合的新开仓节点|等待原分歧恢复、出现可参与的承接证据|不能把“别处也不好”当作失效持仓继续拿的理由|

原则仍为大盘＞板块＞个股；同类赚钱效应用于核验玩法是否适用。收益描述结果，红K频率描述日内正实体出现频率，换手量能与负反馈共同解释可参与性，三者不能互相替代。

建议后续把“环境适用、同类正反馈、参与条件”三栏分开显示。相同模式与相近节点的历史可以研究改善/恶化；跨组总收益不应担任裁判。统一开盘5分钟等时刻不能替代具体模式的确认条件。

## 4. 与现行产品规则的差异

现行产品仍以2.3万亿作为优先A的门槛，2.1/2.3万亿决定7日均额50/100亿容量范围；这是此前用户配置，不是从作者原文拟合出的规律。

此次原文核查表明：**容量限制与玩法选择不应永远绑成一个开关。** 例如21日他仍同时讨论形态首板和抱团，16日也在总量不足时观察到大小票分化。下一轮值得讨论把成交额档只作为容量约束，玩法另由指数位置、资金去向、同类反馈与参与条件判断，并允许主观察和条件备选并存。

本次验收先纠正不合理的收益冠军结论；没有擅自放宽A门槛、启用抱团/接力执行或修改MA5原规则。具体环境判据与量化阈值需要讨论后再落实，不能借作者单次表述自动生效。
