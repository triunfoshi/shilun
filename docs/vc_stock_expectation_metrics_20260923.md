## 1. 本轮已确认的业务原则

1. 指数主要相对昨日收盘比较：是否上涨、站上几根均线、是否多头排列，并观察量能。
2. 方向优先来自短线情绪的题材和板块研究的板块；在板块研究不稳定时额外固定观察AI硬件方向：存储芯片、半导体设备、MLCC、PCB、CPO、交换机、光纤。盘中新出现的板块集中爆发应及时进入观察。
3. 默认套利，买入后的下一交易日评估离场：超预期可继续持有，符合或不及预期默认离场；若这个周期趋势延续更有收益优势，可延长持有。
4. 用户补充确认：只有“符合预期且原逻辑仍成立”时，才允许因没有更好的赚钱效应而继续持有；不及预期或大盘、板块条件失效，不开放这个例外。
5. 证据优先顺序：大盘 > 板块 > 个股。大盘决定适合哪类模式，随后判断板块/情绪方向，再比较个股；不是把“指数必须上涨”作为抱团/接力的共同门槛。
6. 仍保留两类模式、三组反馈和七步链。此处补持有/退出的预案逻辑，不恢复自动执行、交易台账、调仓系统或策略回测的建设范围。
7. 大票沿用过去7个已完成交易日平均成交额的50/100亿标准，按 <50亿、50亿≤均额<100亿、≥100亿分档，不另设市值门槛或新增成交额下限。事件样本在首板日收盘后冻结分档；盘前使用当时已结束交易日，缺完整窗口为未知。
8. 首板溢价按下一交易日开盘制定，固定为该开盘价相对首板收盘价的收益，不再待定开盘/盘中/收盘口径。

## 3. 指数条件如何计算

先沿用项目已有的上证指数、沪深300、深证成指、创业板指，参考[指数复盘规格](index_review_spec.md)。主观察指数和方向参照指数应在预案形成时确定，避免盘中临时挑一条有利的指数。建议上证看大盘总览，其他指数同时呈现分化证据，具体主判组合尚未写成生产规则。

|项目|盘后口径|与昨日比较|
|---|---|---|
|较昨收上涨|`close_t / close_t-1 - 1 > 0`|显示涨跌幅，零涨跌单独标记|
|日K是否收阳|`close_t > open_t`|与“较昨收上涨”分别展示，避免低开收阳但整体仍下跌的混淆|
|站上均线数|建议默认MA5/10/20，逐条判断`close_t > MA_n,t`|显示今日/昨日各站上几根，以及新站上或新跌破哪根|
|多头排列|建议`MA5 > MA10 > MA20`|今日/昨日是否成立；另列各均线斜率，排列与向上不能混成一项|
|均线向上|`MA_n,t > MA_n,t-1`|展示每根方向，不把横向排列自动解释为趋势增强|
|量能|全市场成交额和较昨日增减|继续使用既有2.1/2.3万亿容量档位，明确它与放缩量的区别|

用户提到“红K主要跟昨日收盘比较”，本文在指数判断里将这一意图落实为“较昨收上涨”；标准日K阳线仍单独保留，三类反馈的红K频率不在此静默换口径。“多头并列”按常用含义理解为多头排列。

盘中以最新有效价对昨日收盘价、昨日已冻结均线作参照；如计算包含当前价的当日暂估MA，必须另标“暂估”，不混同盘后确认结果。盘中站回均线与全天收盘站稳不同，记录持续的完整分钟周期和数据时点。

## 4. 方向来源及盘中新爆发

入口为四路合并去重：**短线情绪题材 + 板块研究结果 + AI硬件重点观察名单 + 盘中新增方向**。这只是来源扩充，不增加模式分类。固定观察名单表示保证覆盖，不表示优先买入或预判当天一定强。

板块研究不稳定时，使用可核对日期和成员范围的缓存或人工维护观察组，补实时成员表现；不把缓存的昨日强弱当作今日结论。没有完整成分及行情覆盖时，写“观察组”，不能冒充完整板块资金排名。成员重复去重，CPO、光纤、交换机等交叉归属保留，不能重复汇总成多个独立市场增量。

盘中发现集中爆发时立即新增观察，不必等下一次盘后。建议计算以下证据：

- 同一5分钟内上涨成员占比及上涨成员数。
- 板块成员涨幅中位数减主参照指数同期涨幅，避免仅一个权重大票拉高板块数值。
- 板块5分钟成交额相对前若干交易日同时间段中位成交额的倍数。
- 是否有多个成员同步加强，原核心是否配合，随后一个完整周期是否维持。

首版可试算“至少3只上涨、上涨占比≥60%、中位相对涨幅>0、同时间段成交额≥1.5倍历史中位”作为新增观察提醒；再一根完整5分钟K维持作为扩散延续证据。3只、60%、1.5倍均为可调试算参数，成员规模很小、覆盖不足、指数或行情缺失时不自动判定。首次提醒就进入观察，不把等待第二根K当作延迟发现的前提。

新增观察方向仍沿大盘 > 板块 > 个股筛选，候选仍须满足启用策略。指标齐全意味着值得核验，不意味着立即追涨；同时展示距离预案位置及是否已错过该观察窗口。

## 5. 承接好：四项量化证据

先用完整5分钟K作为讨论粒度；现有数据是否完整需接入前核查。后续有可靠1分钟数据可缩短确认延迟，不用5分钟数据推测其中秒级先后。

|观察项|可计算指标|含义|
|---|---|---|
|均价线支撑|最近窗口内，收盘在对应时点VWAP上方的K线数/有效K线数；当前价与VWAP偏离|是否多数时间保持在当日平均成交价格之上|
|关键位与修复|相对预案关键位的最大跌破幅度、首次跌破到收回的完整周期数、收回后是否再破|卖压出现后能否稳住和修复，不能看到一次反弹就断言承接好|
|回落与再次上攻的量|回落段每分钟成交量/前一上攻段每分钟成交量；再次上攻段每分钟成交量/回落段每分钟成交量|区分回落时成交收敛与放量下跌，并观察修复是否获得成交配合|
|相对板块表现|同窗口个股收益减板块参照收益，另看回撤和修复先后|个股是否比所属方向更主动；不能据此绕过上游否定|

VWAP使用同一会话口径下累计成交额/累计成交股数，股数与手数先统一。采用仅OHLC构造的典型价格近似时须标为近似，不能冒充逐笔成交均价。竞价是否计入需固定，各日保持一致。VWAP定义参照[Charles Schwab指标说明](https://www.schwab.com/learn/story/how-to-use-volume-weighted-indicators-trading)。

关键位在预案中列明，如昨日低点、昨日MA5、已形成的突破位；各位置区分结构失效位与一般观察位。VWAP是动态软参照，短暂跌破不自动等于结构失效。盘中新形成的位置只在形成后生效，不能事后拿全天最低点当作事前支撑。

上攻/回落段可先按相邻完整5分钟K收盘涨跌的连续区段识别，平收结束区段；这只是观测切分，不推定主动买卖或资金身份。只用已经完成的区段，按时间归一；缺前一段、零成交或跨度不可比时显示未发生/不可计算，不能填成满足。

### 建议试算起点

- 窗口15分钟，至少3根完整5分钟K，窗口资料完整；收盘在当时VWAP上方的比例≥2/3，最新一根也在其上。不足窗口先显示初步证据，不伪造确认。
- 若出现一般观察位跌破，记录是否在之后2根完整5分钟K内收回；到期未收回作为修复未兑现。结构失效位按预案直接判定，不给予通用“再等10分钟”。没有发生回落，标“回踩承接尚未验证”。
- 回落段相对前一上攻段的每分钟量比<1，且再次上攻段相对回落段量比>1，可作为较健康的量价配合证据；缺任一段不假定满足。
- 同窗口相对板块收益>0作为择强证据；板块自身仍需成立。

以上只用于试算和解释，不把四项相加成可买分，也不要求任何健康走势都必须经历一次回踩。输出可为“守位成立、回落缩量、修复尚未发生”等证据组合；一次放量上攻而没有回落，不能被描述为已验证回踩承接。

## 6. 超预期：事先区间与当时事实比较

预案先冻结：**比较对象、观察时段、正常范围、超出范围与失效条件**。候选是否持有与新候选资格分开，现有持仓的预期应绑定原套利理由。

|时段|比较指标|正常基准怎样形成|
|---|---|---|
|9:25竞价|相对昨收的开盘幅度、竞价成交额/前日成交额、相对同类竞价强弱|同模式、相近容量、相同涨跌幅制度、相近昨日形态的历史完整样本；或有依据的人工预期|
|开盘首轮观察|价格相对预案位置、相对板块收益、VWAP关系、开盘后回撤|按该机会原定验证窗口比较，不能把竞价强自动延伸为盘中强|
|回落/修复发生后|守位、修复所需时间、量比、再次上攻的相对强度|与自己的冻结预期及同时间同类样本比较|

可试用历史P25—P75为“常见范围”，收益或相对强度超过P75作为超预期候选证据；回撤和修复用相反方向比较。分位数只是一种基准，需保留样本量、时期、条件和覆盖。样本不足时退回明确标注的人工预期，不混合10%/20%/其他涨跌幅制度硬算一组，也不把新股和常规首板混成正常分布。

“统计常见范围”不必然等于这份计划所要求的表现。若买入理由就是次日迅速转强，冻结预案须写出其必要表现；未达到必要条件即不及该预案，即使落在历史中间区间内。反之，原预期明显偏弱，能稳住也可能超预期。无基准只能标“表现强”，不能事后补称超预期。

综合判定顺序：

1. 数据与基准齐不齐；否则未确认，缺数据不等于不及预期。
2. 大盘与方向是否仍支持原模式；上游否定优先处理，不由个股涨幅抵消。
3. 原预案的必要条件及失效条件是否触及；触及失效不以其他强项抵消。
4. 当前价格/相对强度是否超过预设正常范围，并有承接配合；仅成交额更大或净流入排名更高不足以判超预期。
5. 尚未到原定观察时点且未失效，显示等待验证；到期未兑现按原预案判定，不临时延长窗口。

竞价可单独显示“竞价超预期”，下一时段需再验证。建议首版提供9:25竞价、9:35首轮、10:00复核这些模板时点供预案选择，不能一律等到10:00才处理已经失效的预案；15分钟承接统计最早在足量完整数据形成后可用。

假设示例：昨晚正常竞价范围为-1%至+1%，实际+2%只算竞价强于基准；若开盘跌破原预案关键位且没有收回，则不能继续称为整笔计划超预期。上述范围是说明用假设数，不是任何当前股票的测算。

## 7. 套利、次日离场与继续持有

以下为用户确认的决策预案逻辑，尚未接入委托或改变旧MA5持仓管理。

```text
买入后的下一交易日，在原定窗口评估
├─ 大盘/方向失效，或个股不及原预期 → 离场预案
├─ 个股超预期，且上游仍成立 → 继续持有并给下一观察条件
├─ 符合预期
│  ├─ 趋势延续相比其他机会有明确优势，且自身结构/量价仍成立
│  │  → 延长持有预期
│  ├─ 没有更好的赚钱效应，且原逻辑仍成立
│  │  → 可继续持有，但仍按既定条件重新评估
│  └─ 否则 → 按原套利计划离场
└─ 基准/数据不足 → 无法确认；不擅自延长或改写现有管理规则
```

“一直持有”解释为优势与原逻辑持续成立期间持有，每次评估仍检查失效条件；不是只因历史趋势收益较高就永久持有。资金没有更好的去处只对符合预期开放，不用于延迟处理不及预期或上游失效。

### 收益比较需要拆出“次日之后还值不值得拿”

保留三类赚钱效应展示，趋势组内部拆出首板溢价与之后延续，不另增第四种模式：

- 首板溢价（已确认）：`R_open = O_T+1 / C_T - 1`，即首板日收盘至下一交易日开盘；展示百分比时乘100%。下一交易日按交易日历确定，开盘无有效行情时标记缺失，不填0或以之后复牌开盘替代。价格采用同一调整口径；次日收盘反馈另列，不取次日最高价代替开盘溢价。
- 后续延续：统一从下一交易日开盘开始，到后续T+3/T+5等固定收盘时点计算增量收益，`R_continue,k = C_T+k / O_T+1 - 1`；不能把首板溢价再算作继续持有的理由。全程收益为`(1 + R_open) × (1 + R_continue,k) - 1`，不是两段收益直接相加。
- 对比连板/抱团：使用相同截止日期、相同资金占用时长的收益口径，结合红K频率、回撤、可参与性和样本数；必要时展示等效每交易日收益作为辅助，不假定短周期机会每天可重复取得。
- 例如5日8%与1日2%不能直接按总百分比排名。应先对齐机会窗口和持有时长；这些历史对照也不是对未来收益的保证。
- 只使用截至评估日已经结束的观察窗口；尚未走完的T+5样本不补算未来。失败样本保留，不能只取已成为趋势的赢家。

用户将首板溢价作为当前默认捕捉目标；“它的确定性最高”属于待数据检验的策略假设，本文不据此声称已有胜率证明。若首板次日反馈本身也差，仍允许等待，不能因为默认套利就必须出手。

本轮确定的是研究统计基准，实际持有/离场仍按第7节的预期分支讨论；该指标不证明能按首板收盘买到、次日开盘卖到，也不新增自动委托指令。

## 8. 还需固定的少量参数
