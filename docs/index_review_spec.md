# 指数复盘：内容规格与复用清单

更新：2026-09-06。范围：复盘工作区的第一个功能区。

本轮已完成页面目录、区块标题和无障碍名称统一为「指数复盘」。本文明确后续内容编排与代码复用来源；下文标为「归并」「补充」的能力尚未迁入该区块。本轮没有引入外部运行依赖、改变指标算法或交易规则。

## 1. 这个功能区回答什么

指数复盘按选定的已收盘交易日回答：指数处于什么结构，量能是否配合，上涨或下跌是否扩散，当前判断有哪些证据，下一交易日观察什么才算判断得到验证。

沿用已总结的「上升走趋势，弱势走抱团，量能决定进攻市值大小」，展示事实、结构判断和规则边界的对应关系。它给出市场环境，不生成个股委托。来源见 [交易体系 v1.0，第3.2、6.1和6.2节](交易体系/右侧主线套利交易系统_v1.0.md)。

## 2. 应包含的内容与顺序

| 内容区 | 具体展示 | 应让使用者看懂什么 |
| --- | --- | --- |
| 指数总览 | 上证指数、沪深300、深证成指、创业板指；收盘点位、涨跌幅、开高低、振幅、收盘在当日区间的位置、是否站上MA5 | 哪些指数强，哪些弱，是否形成一致方向 |
| 指数结构与关键位 | 可切换指数的日K；MA5/10/20，展开查看MA50/120；上涨/震荡/调整/下跌结构；放量突破、回踩收复、冲高回落等形态；支撑、压力及其计算依据 | 今天是延续、修复、分歧还是破坏结构；判断依赖哪个点位 |
| 量能复盘 | 全市场成交额、较上日增减、MA20及最近20个交易日曲线；所选指数的成交额/MA5/MA20另行标注；现有2.1万亿、2.3万亿和增量1000亿规则标记 | 上涨或下跌有没有量能配合，现有市值边界如何得出 |
| 市场广度与风格 | 上涨/下跌/平盘家数、有效样本数、上涨占比；四指数相对涨跌；创业板与沪深300的相对表现；有数据后再展开中证500/1000等比较 | 指数表现是否得到多数股票支持，权重与成长是否分化 |
| 机构旁证 | IF/IH/IC/IM前20席位净持仓、核心席位净持仓；具备同口径前日数据时显示变动；单独显示来源日期及滞后情况 | 机构期指持仓是否支持现货判断；持仓是旁证，不等同于现货净流入 |
| 当日结论与环境边界 | 趋势进攻/轮动等待/弱势抱团；列出指数、MA、广度、量能依据，解释规则给出的风格与市值范围；证据缺失时显示待确认 | 判断为什么成立，哪些证据发生变化就需要调整判断 |
| 昨日回证与次日验证 | 昨日冻结条件→今日实际→成立/不成立/数据不足；今日再生成下一交易日的指数关键位、量能和广度观察条件 | 让每天的判断可对账，避免用事后解释替换原判断 |

外围环境作为可展开的辅助区：美股、港股主要指数，按需加入科技龙头；每条显示所属交易场次。它不是首版前置条件，也不应抢占A股指数主体。

建议的阅读顺序为：数据日期与覆盖 → 指数总览 → 日K与关键位 → 量能及广度 → 机构旁证 → 当日结论 → 次日验证。默认只展开一个指数的详细图，避免四套长图重复占位。

## 5. 必须补齐的连接与口径

1. **日期一致性。** 当前复盘`_indices()`取各指数截至复盘日的最后一根，需进一步区分同日、滞后和缺失；缺指数不得按下跌计入姿态。研究结果按「指数+复盘日期」提取，不混用最新研究缓存。外部实时指数接口没有目标日期，不直接用于历史复盘。
2. **历史长度。** 当前复盘指数只取约6日，只够短期摘要；引入MA20/50/120和日K图需要扩充指数历史。已有研究均线允许不足整窗的计算，正式展示须给出样本覆盖；不足满窗时明确标记。摆动高低点还应记录确认日，不能把之后才确认的端点写回较早快照。
3. **量能口径。** 全市场成交额来自有效个股日线之和；所选指数成交额是另一字段；不得将相互重叠的四指数成交额相加充当全市场。2.1/2.3万亿与1000亿为已冻结项目规则，首版沿用，同时标注市场范围、规则版本；不是跨时期自动有效的常数。外部涨跌幅百分点与石论小数比率须在适配处统一。
4. **指数专属回证。** 现有复盘`expectations`基于情绪/涨停标签，不能直接充当指数回证。新增验证记录至少保存：复盘日、目标交易日、指数/指标、今日基准值、比较方式、固定点位或阈值、观察时点、规则版本、结果和缺数原因。点位条件需要支持「收盘站上/跌破」等比较，不能仅套用上升/下降。
5. **只读取已生成快照。** 继续沿用日终任务生成、页面读取的方式；打开页面不临时扫描全市场。本轮新增指数字段保持向后兼容，旧快照不会被静默改写；下一次生成收盘快照后出现新字段，结构规则稳定后再升级快照版本并批量重建所需日期。

验证表达示例（结构模板，不是当前市场判断）：昨日记录「下一交易日收盘守住昨日已冻结支撑位」，今日显示「实际收盘、冻结支撑位、成立/不成立/数据不足」；再记录下一交易日量能相对今日基线的条件。验证结果保留原记录，不事后改写阈值。

## 6. 与其他复盘区块的归属

- 目标结构：把当前第二栏「大盘与量能」中的四指数、全市场量能、广度和期指证据归并到指数复盘，后续不重复保留整套第二栏。
- 当前第一栏中的情绪周期预期差、涨停标签预期差回到「预期回证」；连板梯队、龙头谱系留在「市场情绪」。
- 三战法候选与个股名单留在候选区；总体执行纪律和跨板块结论保留在复盘摘要。
- 大盘研究仍提供深入取证入口，与指数复盘共用计算结果，不复制一套判定算法。
