# 全站统一分类与周期诊断

## 本次范围

实施短线题材路线的第一项：独立分类目录、唯一分类来源、行业 ID 关联、周期缺口诊断。三连板且首板起十个交易日内至少五板的新资格规则、15% 收盘回撤与新连板段独立认证保留为下一项，未在本次替换现有筛选算法。

## 唯一来源与层级

- 分类供应方统一为东方财富，通过既有 Tushare 兼容通道读取 `dc_index` / `dc_member`。行情、资金流、涨停原因各自保留事实来源，不作为第二套分类。
- 全量目录单独保存，不从 P2 排名、前 3/8 个板块或 50 家成员限制反推目录。研究筛选使用概念和三级行业，一级、二级行业只作归属背景，地域保留在全量目录。
- 每项保留 DC ID、原名、类型、行业层级、成分日期、抓取时间、版本与成分校验摘要。同行业 ID 只出现一次，同名概念/行业明确区分类型。
- `dc_index` 未提供父级 ID。父级仅在同日成分集合唯一包含时关联，注明 `membership_inferred`；没有唯一匹配就记录缺口，不猜名称、不借用申万关系。
- 当前目录可以保留比 50 家更大的概念。P2 当前的成员上限仍属于筛选规则；它将由路线第三项的发酵筛选升级，不影响本次全量目录。

## 发布和历史处理

新增集合：`market_taxonomy_catalog`（待发布目录）、`market_taxonomy_members`（按日期与内容摘要保存成分）、`market_taxonomy_stocks`（按版本反向索引）、`market_taxonomy_snapshots`（完整发布清单）。逐板块验证日期、代码、唯一性与 5000 条截断上限；失败仅保存待补记录，全部完成后才发布。重试复用已核验成分。

原 `review_topic_catalog`、`review_topic_members`、`review_industry_members` 和旧版本复盘保留，生产分类不再调用同花顺/申万同步。旧来源同名项不自动映射为相同实体。原始 `stock_basic.industry` 保留作上游原始字段，展示/计算覆盖时记为 `raw_industry`。

复盘版本升级为 `daily_review_v1.9_eastmoney_taxonomy`；题材版本 `perspectives-v4-eastmoney`；板块版本 `market_sector_v15_eastmoney`；市场版本 `market_part1_v5_eastmoney`。旧缓存不会被当作新分类结果返回。历史日期尚未迁移时显示分类缺口，不用最新成分冒充历史，也不退回旧来源。按日期查询的成分记录是重建证据，尚未证明其当时的发布时点，不能直接用于严格事前回测。

## 周期待确认诊断

| 状态 | 含义 | 处理 |
|---|---|---|
| 数据待补齐 | 当前/前日板池、开板次数、广度或资金流有缺口 | 指明缺失输入，补数后重算；缺失不作零 |
| 分类关联待补齐 | 没有唯一三级行业 ID 或分类同步未完成 | 查目录同步及成分冲突 |
| 周期计算待完成 | 行业 ID 存在但该日周期结果不存在 | 重建所选日复盘 |
| 暂无短线涨停结构 | 数据已就绪，无涨停且未满足衰减规则 | 保留趋势研究背景，等待短线供给 |
| 阶段证据不足 | 数据有了，但现行阶段规则未命中 | 展示实际首板、涨停、最高板数；后续状态机升级校准 |
