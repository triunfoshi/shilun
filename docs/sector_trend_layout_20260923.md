# 中期趋势候选：排版修复

## 原因与调整

旧切换器将8个板块放入最小138px的网格，同时按钮禁止换行；完整的“中期趋势／阶段／主线分”文字宽于按钮，导致相邻文字重叠。旧摘要还继承了大卡片和胶囊间距，与全站终端密度不一致。

- 切换器改为“板块名称、阶段、趋势分”三列单行，名称、阶段、数字各有独立空间；整组根据可用宽度换行。完整名称通过 title 和无障碍标签保留。
- 沿用全站12–14px字体、8px间距、细线边框和4px面板圆角。桌面按钮28px，小屏与触屏44px。
- 排名摘要改为紧凑信息带；基准、来源和状态计数同行排列，来源长说明原文保留在折叠区。
- 当前详情采用统一内边距；板块目录改为正常文档布局，避免悬浮标签遮住标题。
- 切换按钮增加 `aria-pressed`；重绘后恢复焦点，Tab、Enter可连续操作。

不改数据来源、板块名单、分数、排序或MA5入选逻辑。沿用 `design.md` 和共享 tokens，没有引入新字体或依赖。
