# R2 与 P2 统一细分成分

2026-09-15，板块引擎 `market_sector_v13_p2_memberships`。

R2 从 `review_topic_perspectives` 读取与 P2 相同日期、相同版本的完整细分成分归档。缺归档时，板块预计算调用现有 P2 同步流程补齐；无法取得有效成分则报错，不回退到 `stock_basic.industry`。

## 共用的划分

- 同花顺概念：沿用 `ths_topic_kind` 的项目范围排除规则；CPO、PCB 概念按原代码和原成分计算。
- 同花顺 884 细分行业。
- 申万三级行业：保留一、二级归属路径，一级、二级不参与排名。
- 同名不同代码的行业分开计算并附来源，如「印制电路板 · 同花顺细分行业」与「印制电路板 · 申万三级行业」，不合并成分。
- 2026-09-15 归档共843个视角：365个同花顺概念、232个同花顺细分行业、246个申万三级行业，合计70,424条成员关系。

## 保留的 R2 规则

中期趋势分、20/60日强弱、成交额、广度、核心反馈、候选股票与分钟资格门继续使用原规则；不应用 P2 的短线三板/二板准入或当日选中状态。保留 R2 原有排除 ST 配置；每日至少5只有行情成分且覆盖归档成员80%才计算该视角。

全市场成交额在成员展开前按股票和日期去重。某股票可以计入多个独立视角，但不会把这些视角的成交额合计误当成全市场成交额。同一股票的基础滚动指标和相对大盘分钟计算只计算一次，板块内分位与相对板块评分仍分别计算。

历史窗口固定使用此次归档的成分，页面保留采集日期与成分重建说明；没有将最新成分回看包装为历史时点回测。

## 缓存与接口

- 引擎版本更新，旧行业代理缓存不再命中；既有旧档不删除。
- 全视角保留分数、状态、成员、资金与分钟短名单；重型个股明细只随顶部板块返回，避免843个视角重复传输并超出Mongo单文档大小。
- 选品候选沿用同一份板块计算输出，不另建一套成员库；龙头榜没有重新启用。
- 原纯计算函数的无成分参数路径保留为历史兼容调用；R2所有预计算入口显式传入P2成分。
- 查询不初始化全库索引，云端缓存读取总预算30秒；网络超时返回503，与真实缺档的400分开，避免已计算结果误报未预计算。

## 验证

67项Python测试通过，包含同名行业隔离、概念与细分行业过滤、无旧industry字段时真实成分归属、重合成员去重分母、80%覆盖门槛、空归档不回退、两轮计算复用同一成分、缓存存在/缺档/网络超时分流、分钟资格门及选品/持仓上下文回归。三组前端既有渲染检查通过。

旧汇总与新向量化汇总分别比较有/无资金数据、有/无成交额四种场景，所有数值在1e-10容差内一致。

真实重算：2026-09-15，843个归档视角中817个满足R2当日覆盖要求；耗时320.8秒。102只候选分钟覆盖102/102，补齐77只，严格资格门已通过。新缓存BSON约6.80MB，已落云端；本地后台已重启读取新版本。
