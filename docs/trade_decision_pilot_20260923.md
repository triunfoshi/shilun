# 交易决策测试版：实施与核查记录（2026-09-23）

> 本文为首版历史记录。当前生效的中位数、历史核心、3＋2方向与流程图口径见 [第二版说明](trade_decision_v2_20260923.md)。


本版是基于日期缓存的分析与观察工具。已落地七步证据展示、条件分支、MA5资格池、冻结盘后预案与下一交易日缓存跟踪；没有把数据缺口包装为自动决策闭环。

## 页面与运行方式

- 交易 → 交易决策 → 明日预案 / 今日跟踪；原交易权限保留在交易决策入口。
- 明日预案：选择已收盘日期，读取或生成并冻结预案。C01—C06逐层展开；C07指向次日验证。
- 今日跟踪：选择盘后依据日，跟踪其下一交易日；时点可留空或指定。可每30秒读取已有缓存，离开页面或浏览器隐藏后暂停。
- 历史日默认截止15:00，明确显示实际日期。所选日缺预案，不回退其他日期。
- 现阶段每日期首次生成即冻结，重复生成读取该版本，不覆盖旧基准。尚未建设多版本编辑与人工确认工作流。
- 原MA5筛选、交易闸门、持仓和订单流程未接入本模块。
