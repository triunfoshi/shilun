# 首板前二行业历史统计修复（2026-09-24）

## 原因与修复

统一分类后，正式分类目录只覆盖9月21—23日。打板效应把旧日缺失的行业归属清空，却把筛选出的空列表记作“无样本、名单完整”。此外，原关联使用反馈日的分类，而不是首板发生日。

- 继续使用东方财富 `dc_index` / `dc_member` 与统一分类中心的日期、DC ID 和成分校验。
- 补齐8月12日至9月18日28个交易日，每日337个三级行业。按行业跨日读取，达到5000条时拆分日期；日期、代码、重复、空成分校验失败不发布该日。
- 原始目录、成分和证券索引复用现有集合。历史行业投影以 `eastmoney-taxonomy-v1:industry_l3:日期` 发布，只有明确请求行业的消费者可读取；不会被完整概念目录的消费者误认为全量分类。完整同日快照优先。
- 先用首板日的完整涨停池计算行业涨停数，再选前二行业的首板股。并列按行业代码排序；次日行情缺失、反馈源漏股或封板时间缺失不改变行业排名。
- 首板样本仍要求有效的最终封板时间。次日价格缺失保留在样本总数中，不补零。行业归属缺失的日期标为待补齐，不算入名单覆盖；七日滚动曲线保留真实缺口。
- 展开日趋势可查看首板日、前二行业、行业涨停数；原始样本增加首板日行业。
- “刷新统计”会补齐该窗口缺少的历史行业。独立补齐可用：`./.venv312/bin/python -m shilun.jobs.taxonomy_sync_job --start 2026-08-12 --date 2026-09-23 --industries-only`。此补齐不引入额外定时器。

历史成分是按对应日期事后采集的重建数据，并不证明当日盘中已发布；没有用最新成分回填旧日。
