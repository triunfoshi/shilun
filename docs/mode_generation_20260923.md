## 修复

- 后台按读取阶段、计算阶段返回任务进度和已用秒数，并记录阶段日志。
- 整体数据库读取设置600秒预算；失败提示保留发生阶段，不泄露连接详情。
- 任务提交失败、工作线程异常退出均落为error，允许重试，避免遗留running状态。
- 完成回调在锁外注册，避免已完成Future立即调用回调时重复取锁；旧任务回调不覆盖新任务。
- 前端状态请求30秒超时；生成时显示阶段/耗时，失败停止轮询；完成后显示当日结果。
- 静态脚本缓存版本升至v8，本地后台已重启生效。
