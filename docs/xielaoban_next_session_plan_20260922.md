## 1. 作者当时已经给出的方向

**原文 A424:P05（9月18日）**：他事先准备了两个分支：周一指数继续放量强势，就观察大资金共振与大票首板；科技分歧，则抱团继续加强。

## 5. 为什么这样做：三个实操片段和一组反例

1. **先写分支，再让市场选择。** A424:P05先写“放量强势看大票首板/科技分歧看抱团”，A425:P03—P05再根据次日反馈偏向抱团。可学习的是同一组条件贯穿前后，而非事后给涨得最好的票贴核心标签。
2. **弱预期下能稳住，也可能是超预期。** A415:P05作者自述，席位退出后他原本预期“大米”走弱，但9月4日早盘在均线附近稳住，因此上调判断；文内截图I01显示9月4日14:07已作积极评价。这里学习“预期与现实的差值”，不把作者自述的席位原因当作独立核实事实，也不把所有低开都定性成机会。
3. **趋势退出必须有环境前提。** A334:P04、P06记录作者处理趋势持仓，并明确指出指数不再主升时不要盲用五日线。因此，均线形态合格只解决观察资格，不独立决定开仓；不能套用一条线而忽略玩法是否仍被资金支持。
4. **信心很强也会遇到右侧失败。** A349:P03—P05自述指数企稳后把亨通加满；A350:P04次日承认右侧企稳失败、大票放量下跌。本文保留这一反例，故B分支必须配套取消和退出条件，不照搬作者满仓表达。

已有持仓与新开仓分开：抱团单按核心地位和原定弱转强逻辑验证；趋势单按结构和环境验证。隔夜跳空、跌停或一字无法正常成交都可能使计划价格不可达。用户尚未给这类计划的独立风险预算，本文不编造仓位比例、交易数量或统一止损百分比。

## 6. 下一步讨论线上化时应保留的对象

建议先把它做成一张可核对的计划卡，流程为：**当日事实 → 当前主次模式 → 核心角色与反证 → 正常预期 → 确认/失效条件 → 策略许可 → 盘中更新与复盘。**

每条计划最低保留：事实截止时间、目标交易日、策略/模式、观察对象及角色、作者来源、支持证据、反对证据、正常剧本、触发窗口、确认条件、取消条件、持仓处理原则、风险预算、数据缺口。任何状态更新都记录当时可见证据，不能用盘后新增信息重写原判断。

可以直接复用的事实：指数位置与量能、市场广度、昨日强股反馈、梯队/断板、板块前后排、7日均额与MA5资格。尚不应伪装成完整的能力：真正的主动带动因果、昵称自动映射、实时异动空间、同时间段量能对比、盘中持续承接、未核验公告。当前25只MA5的同日分钟共振均仍待确认，日线归档质量通过不等于个股分钟执行许可通过。

第一轮讨论建议围绕：是否认同“抱团核心为主、科技确认后再升级”的主次；是否把独立的抱团观察池纳入计划层；预期失败后哪些情况取消新仓、哪些情况处理已有仓位。参数和执行自动化应在这些语义确定后再定。
