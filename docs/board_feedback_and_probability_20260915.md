## 次日涨停概率：建议分两阶段

第一阶段展示“历史同类晋级率”，按今日板数、交易板涨跌幅制度、ST状态、换手/一字分别建立可核验样本。先显示命中数/有效数、覆盖日期及不确定区间；样本少则展示样本不足或退回更宽分组。不能把某一组频率包装成某只股票的精确概率。

事件定义：T日收盘在天梯的个股，在下一交易日T+1收盘仍封涨停（连板晋级）。触及涨停后炸板不算成功。报价缺失、停牌、池不完整分别标记，不能直接算失败。历史名单保留所有失败者，不只读取次日幸存股票。

当前30个反馈交易日归档里，昨日5板样本只有14条（其中6条次日收盘涨停）；两者都只是已观察的股票-日期样本，同一个股连板及同日市场环境存在相关性，不能视为14次完全独立试验。进一步按情绪、板型、题材切片会更稀疏，因此尚不足以给今日5板个股提供可信的个性化概率。该统计未按10%/20%、ST及交易可达性进一步分层，不直接作为交易决策。

第二阶段才评估“个股条件概率”，需要：

1. 仅使用T日收盘已知的环境、相对高度、板型、封板时间、开板次数、成交量价与题材角色。T+1开盘、最高价和最终晋级结果不能进入T日预测特征。题材成员必须有历史时点证明，当前成分重建不能冒充当时已知。
2. 按日期先后滚动训练/验证，同一天整体放在同一段；相邻事件和重叠标签在边界处理，防止泄漏。对照“只按板数的历史概率”基准，再看复杂条件是否有稳定增益。
3. 评估概率校准（预测约30%的样本，实际是否接近30%）、Brier分数及分层样本数量；不能只汇报分类正确率。Brier分数包含区分能力和校准，不应单独作为校准证明。
4. 将“次日封板概率”与“可成交后盈利概率”分别定义。前者高，可能只是次日一字封死；不意味着可以按显示价格成交。退出收益仍需次日套利研究中的真实可执行规则、费用及分钟回放。

本次未上线个股概率，继续遵守暂不增加AI功能的约定。可先复用现有归档做同类条件统计；概率模型是否值得加入，以时间外验证结果决定。

统计方法参考：[NIST比例置信区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)、[scikit-learn概率校准](https://scikit-learn.org/1.8/modules/calibration.html)、[数据泄漏说明](https://github.com/scikit-learn/scikit-learn/blob/main/doc/common_pitfalls.rst)。普通二项区间依赖简化假设，正式评估应同时考虑按交易日聚集的相关性与市场状态变化。
