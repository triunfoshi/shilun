# 短线情绪：Vibe 事件题材与三页签

2026-11-02，根据已确认布局实施。原版参考：Vibe-Astock `e0d08d19848b50d22a772729a06287cdff511629`，Apache-2.0；图标保留 Lucide 原始 SVG，ISC 许可见 `licenses/lucide.txt`。

## 页面

- 今日情绪：当日档位、赚钱效应/晋级率/封板质量、题材事件树（左）和情绪周期/行业发酵节奏（右）、独立实时行情、收盘验证与跌停风险。
- 题材轮动：近五个交易日矩阵、跨日题材周期、默认可见的同日题材证据。轮动保留当日前12题材与昨日至少2家而今日消失的题材；不受已验证方向最多3个的限制。
- 情绪历史：10/20/30/60日窗口，默认30日；历史统计位置、与前一有效交易日比较、六项逐日读数、缺口来源。原晋级/炸板日趋势移入折叠补充区。

三个吸顶页签共用复盘日期，切换不修改日期。历史比较明确显示被比较日期，不将非交易日或缺失日伪装成昨日。窄屏卡片纵排，矩阵及历史表格在各自容器内滚动。

## 同一套事件标签

`vibe_shortline.clean_reason/tags_of` 复用原版完整标签截断及属性词过滤；不做 DC 分类映射、行业替代或主线别名合并。一只股票可对应多个事件。

事件树、轮动、同日证据、新周期输入和短线决策来源统一采用 `vibe-event-themes-v1`。事件 ID 为标签的稳定摘要。历史观察成员仅从当时已经出现的原因累积，后续扩散仍须命中对应日期原因；缺原因不能推断为已退出、未扩散或零收益。行业结构单独维持行业视角。

旧周期保留原始归档。新周期及归因两份清单均带口径标记，使用现有原子发布指针；旧 DC 归档不直接改名为事件题材。原五板核心资格、固定前后排名单和阶段转换规则继续独立运作，因此事件树中出现的题材不一定满足跨日周期准入。

## 数据读取与口径

新增只读接口：`/api/v1/review/shortline/themes` 和 `/api/v1/review/shortline/history`。有30秒缓存和并发请求合并；`refresh=true`仅重读数据库，不发起上游回补或重写历史。回补仍通过已有可跟踪任务触发。

轮动 `—` 是未知，`·` 是已确认没有。10月28日原始池72家包含北交所2家；题材范围沪深非ST70家，原因覆盖69家、缺1家。列头按Vibe展示原始池总数，北交所不计入题材或缺原因，范围说明保留在列头及口径浮层。

历史六项：涨停家数、最高连板、炸板率、昨日涨停股今日收益中位数、昨日涨停股跌超5%家数、1进2晋级率。分位仅与所选日前有效读数比较，至少10个样本；85%/15%标记极端。收益、涨跌幅变化和比例变化分别保留正确单位。部分行情或停牌不补零；缺口显式保留。

打板效应另修正：全体涨停以完整昨日收盘涨停名单为样本，保留无最终封板时间及缺收益股票；炸板是独立风险对照。前端不再把空超额值误标为“基准”，名称统一为“全体涨停”。
