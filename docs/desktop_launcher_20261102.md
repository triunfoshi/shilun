# 桌面启动器修复验收

日期：2026-11-02，Asia/Shanghai。

实际复现桌面“石论后台.app”（显示名称“瑞势投研”）点击后弹出“分钟线日终同步服务注册失败”，当时8000端口没有后台，`cn.shilun.backend`未注册。`launchctl print-disabled`确认分钟线和Tushare日线任务已禁用，桌面应用签名原本有效，图片没有损坏。旧启动器先注册所有附属任务、失败即退出，因此禁用的同步任务挡住了网页启动。

修改`石论后台.app/Contents/MacOS/shilun-launcher`：先确认/启动原后台并打开原`http://127.0.0.1:8000/ui`；附属任务沿用原所有者，显式禁用则跳过，配置缺失/注册失败只记日志；不自动enable既有禁用任务。浏览器打开失败仍明确报错，无弹窗验证模式不调用系统弹窗。

实际桌面应用已备份后更新启动程序，保留“瑞势投研”名称和原ICNS图标，构建版本1→2，重新签名并通过严格签名校验。原应用备份位于`runtime/launcher-backups/20261102-152919/石论后台.app`。部署回执见`outputs/01a17178-dec2-7a91-91e1-cc7e68aa661e/launcher_fix_20261102/desktop_update_receipt.json`。
