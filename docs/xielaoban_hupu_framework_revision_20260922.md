## 2. 对原决策系统的十项实质修正

### 2.1 “模式”应从宽泛玩法变成条件组合

**作者依据：**2026-07-22，H01以固定的日K形态、分时形态、指数形态、情绪节点组合来解释模式。2025-12-26，H50建议能力不足时先专注单一模式，有匹配机会才做；2026-09-17，H24强调多种玩法能赚钱，并不代表同一个人都应参与。

**修订：**原来的容量趋势、情绪接力、抱团、轮动套利改称“市场玩法”。完整交易模式还需写清适用环境、节点、结构、角色、买卖触发、期限和失败条件。前四个组合维度来自H01，其余是为检验和执行补充。不能因市场中某类股票涨得好就自动启用所有相关策略。

产品应分别回答：市场发生了什么？我已经验证、能执行的模式中，哪一个适用？没有匹配模式时允许空仓。H01中作者声称的高胜率没有交易数据支持，不作为参数或承诺。

### 2.2 盘前预案负责准备分支，临盘负责产生事实

**作者依据：**H02强调短线买入信号来自当时盘口；H03甚至质疑大部分交易日复盘计划的作用；H04说自己偏重形态和盘口。这与他持续发布复盘、又在H28要求系统复盘历史的做法并存。

**修订：**保留这处张力，不替作者解释为从未矛盾。系统的盘前产物应是“假设、观察对象、应该看到的表现、否定条件”，而非一条预先写死的买入指令。到了盘中，只有当时已经可知的事实才能更新计划。预案价值需要通过减少误操作、识别失效等可检验结果来评估。

同时，H05在回答均线拿票问题时自称只看日K审美、不关注分时。这不能与盘口至上强行合并成所有交易都依赖同一种秒级信号。选股依据、入场方法与持仓管理必须分开记录。

### 2.3 核心可以不存在；观察核心也可以交易跟随者

**作者依据：**H07描述过低位首板分散推进、缺少单一核心的环境；H15明确描述等最高标结束分歧后，参与最强跟随股的套利；H43解释高低切是相对梯队关系，不固定为一进二。

**修订：**观察名单增加三类角色：环境参照、执行候选、反证样本。核心状态允许“明确、竞争中、不明确、当前不适用”。板块没有公认核心时，可以看同类群体的承接广度，不能为了填表硬选龙头。

“最强跟随股”必须在预先定义的比较群体、时点和套利条件下识别，不能把所有后排都合理化为补涨机会。H07关于特定资金引导量化的因果、H15关于低风险的自评，均未经独立核验。

### 2.4 同一只股票可以对应不同动作，模式必须绑定持仓

**作者依据：**2025-02-20的H06对航锦科技指出：按趋势看，远离均线可以是卖点；按抱团看，又可以是激进参与点，面临另一种失败风险。

**修订：**股票不只拥有一个“买/卖总分”。每个计划必须带模式ID、版本、进入理由、持有期限和失败条件。同一时刻的不同研究计划可以并存，但账户持仓管理必须知道自己执行的是哪一个。

允许基于新证据升级计划，并留下修改记录；不允许因为原逻辑失败就改名为另一种模式继续等待。

### 2.5 市场好、持仓好、新开仓好，是三个判断

**作者依据：**H14把低位走强但已普遍加速的局面称为持股行情。H22则观察到趋势分歧后，抱团并未按预期加强，选择等待。

**修订：**每个模式至少分别输出环境适用性、已有仓位有效性、新开仓机会。强势持仓可继续观察，但新开可能已错过价格或换手窗口。趋势走弱也不自动推出抱团可买；替代分支必须自己通过验证。

### 2.6 作者既做确认，也做预判；时间窗口不能统一

**作者依据：**H19自述在预判后提前点火；H20明确承认竞价参与基于预判。H17曾对特定反包机会给出开盘等5分钟的处理，H18又描述另一类持仓前5分钟通常不看。

**修订：**确认型记录已发生的事件；预判型记录待发生的假设及兑现期限。不能把提前下注重写为“系统已经确认”。预判型的可重复条件未研究清楚前，保留为研究样本。

窗口由交易理由决定：快速弱转强看短窗口兑现；趋势回踩看结构和修复；尾盘套利看当日轮动及隔夜理由。9:35、10:00等只可作为具体模式的待验证检查点，不能建立统一全市场确认时刻。

### 2.7 “上攻坚决”必须与换手、承接、位置和买得到联系起来

**作者依据：**H09在2024年底警告缩量直线首板；H10在2026年4月又对一组缩量首板表示积极；H11也存在对缩量板的不同态度。H12—H13指出跟随者可能买不到盈利板，却买入后来炸掉的票。

**修订：**速度快、距离涨停近、MA5向上只能是特征，不能单独生成确认。要研究同期量价推进、实际卖压后的维持、同类反馈和买点是否仍有效。“缩量首板”也不能一刀切禁止，应按位置、环境、换手过程和进场方式分组验证。

信号研究必须同时保留未成交与失败样本，分开报告理论机会、真实可成交机会和实际成交结果。五分钟K线不能恢复封板瞬间的排队、撤单与成交次序；分钟形态研究和实时打板执行属于不同数据要求。

### 2.8 容量约束要绑定市场、玩法和自己的体量

**作者依据：**2024-11-21，H16用“前一日成交额50亿”约束当时接力；H44又从个人仓位容量角度讨论成交额较小的票。H32在9月21日按体量表达抱团偏好。

**修订：**用户现行的2.1/2.3万亿档位与7日均额50/100亿，应作为独立用户配置保留，不能借H16说成作者验证过的阈值。还应研究这次换手需要多少流动性、同类容量票是否有承接、自己的下单工具与资金能否匹配。

前日额、7日均额、盘中已成交额、全天预测额必须分字段，不能互相替代；盘中全天预测额也不能当作已实现事实。

### 2.9 动态调整既要记录新证据，也要允许“不知道原因”

**作者依据：**H33—H37是9月16日连续表态；H39—H41是9月14日至15日看好穿越后失败并承认没看懂的反例。H21提醒依赖量化行为的模式可能失效。

**修订：**把调整拆成环境判断更新、未成交计划撤销、持仓管理更新、新计划建立四种事件。每次记录旧假设、新事实、时间、动作和未知项。不能由作者的一句重新参与补造完整的风险预算与成交路径。

一次失败需要按原计划处理；持续样本退化需要暂停具体模式并重新验证。退出并不要求先找出能令人满意的故事原因。

### 2.10 仓位观点存在冲突，能力边界比模仿仓位更稳定

**作者依据：**H46提醒连板分仓；H26给固定单票金额与缓冲资金示例；H47、H27又建议一定资金规模以下不分仓。可比条件不充分，不能把这些说法拟合成一张统一仓位表。

**修订：**不采用作者某次满仓、单票比例或资金阈值作为默认值。保留可复核的个人模式范围、单笔失败预算、组合相关性、可卖约束及执行能力。H25明确强调打磨自己的系统，不因别人重仓就认为自己守纪律有错。

## 6. 后续线上化应优先补什么

先做四类互相关联的数据记录：玩法与样本反馈、观察角色、具体模式计划、执行与修订记录。连接键至少包括交易日、事实可知时间、模式ID、计划版本、标的、观察角色和持有期限。

最先补齐的研究缺口是：

1. **具体模式的条件字典**：把日K形态、分时形态、指数结构与情绪节点拆成可观测定义，允许尚不可量化的人工判断保持空缺。
2. **同类完整样本**：以触发时名单为准，涵盖没上板、炸板、未成交和错过价格者；不要用收盘赢家反推早盘名单。
3. **观察到动作的映射**：同一个环境信号分别对持有、开仓、等待产生什么影响；对不同模式采用不同窗口。
4. **执行现实**：核验数据延迟、实际可成交价格、排队与成交选择偏差；盘口数据不足时先研究分钟形态，保留打板能力缺口。
5. **修订依据**：记录失败与未知原因，比较某次失误和模式持续退化；先用冻结时点回放检验，再讨论接入执行。

目前最有价值的可交付定义是：**每一个候选都应同时附带“为何今天属于我的模式、观察谁、等什么事实、何时失效、当前是持有机会还是新开机会”。** 这层条件计划，负责把大盘、板块和情绪分析连接到MA5等执行策略。
