# VC-stock 交易决策接入建议：分析 + 实时（v6）

初稿：2026-09-22；更新：2026-09-23。状态：产品与规则讨论，尚未新增页面或修改生产逻辑。当前范围为两类模式、七步链、三组反馈，以及用户确认的指数判据、方向来源、次日套利/持有原则和大盘 > 板块 > 个股顺序，详见[七步决策链](vc_stock_decision_chain_spec_20260922.md)与[承接及预期量化补充](vc_stock_expectation_metrics_20260923.md)。此前十步方案已[归档](evidence/vc-stock-decision-design/vc_stock_decision_integration_proposal_20260922_before_two_modes.md)。

## 1. 本版要交付的能力

把市场事实组织成一条可以逐步核对的分析链：

**指数量能 → 趋势/连板/抱团三类反馈 → 大票首板套利或情绪抱团/接力 → 板块与观察核心 → 策略与主备候选 → 次日预期 → 竞价及盘中核验。**

当前结果是“方向是否成立、看谁、优先哪个候选、为什么、次日套利还是继续持有、还需看什么”。本轮新增的是持有/退出的预案判断，不是委托、仓位管理引擎或旧MA5退出规则的修改。执行检查、仓位动态调整、复盘反馈、回测和台账仍在当前建设范围之外。

作者依据来自[对K1ayThompson的回复证据](evidence/xielaoban-hupu-20260922/k1ay-simplification-evidence.md)。作者讨论的“指数调整看小票、指数上涨看科技大票”支持方向选择；数值门槛和本版产品规则属于用户参数及设计讨论。

## 2. 信息架构

```text
交易
└─ 交易决策
   ├─ 明日预案
   └─ 今日跟踪
```

保留已确定的两个页面名称；内容按**分析 + 实时**分工：

|业务组织|页面落点|展示内容|
|---|---|---|
|分析 · 历史研究|明日预案的历史对照入口；今日跟踪可引用|三类群体在历史环境下的表现，注明统计日与样本口径|
|分析 · 每日盘后|明日预案主体；今日跟踪引用昨日基线|当日事实、方向判断、主备候选、下一交易日预期|
|实时 · 盘前竞价|今日跟踪|逐层对照竞价是否符合昨日预期，调整候选观察顺序|
|实时 · 盘中|今日跟踪|指数量能、板块/核心和候选的同时间对照，以及尚待出现的条件|

收盘后生成“当日盘后分析”，用于下一交易日预案；昨日盘后只是今日跟踪对上一交易日分析的引用。历史研究在此指市场风格与群体反馈对照，策略收益回测后置。

两页都展示C01—C07的对照条。每一步显示结论、来源时点、主要证据、缺失项；技术版本放详情。没有适用方向、没有兼容策略或没有合格候选，都应明确呈现，不能用空列表代替解释。

## 3. 最小业务对象

不再建设多层模式分类或通用模式研究平台。当前只需三类连接对象：

|对象|最少内容|作用|
|---|---|---|
|方向判断|交易日、截至时点、A/B或等待、相对昨收的指数量能/均线与三类反馈依据|说明为什么优先这条方向，冲突按大盘 > 板块 > 个股解释|
|观察预案|方向来源及比较依据、板块/情绪组、核心参照、次日套利与持有例外、验证期限、策略建议、主备候选、正常/超预期/不及预期条件|连接市场判断与个股观察，区分新候选与已持仓预期|
|实时对照|对应预案、行情时点、各层实际表现、候选优先级、变化原因、下一观察条件|把“昨晚预期”与“现在实际”并排展示|

代码中模式只需稳定标识`large_cap_first_board`和`emotion_cluster_or_relay`。接力/抱团偏好、核心承接/启动扩散等作为结论或观察项保存，不再扩成模式ID。MA5是独立策略ID，不充当模式ID。

观察核心与候选分别保存。中际旭创、新易盛这类例子不能永久写入配置；同一股票在不同日期可能承担不同角色。未确认的核心身份允许保留人工判断、依据和时点。当前无需新增成交、仓位或回测生命周期对象。

## 5. 两类模式怎样选

分析阶段以已完成交易日的市场成交额作基线：

1. 大于2.3万亿，指数上行且趋势反馈支持，优先大票首板套利；随后比较板块和容量核心，不能由量能直接推导CPO。
2. 不足或等于2.3万亿，先比较情绪抱团/接力；连板好偏接力，连板弱而抱团核心强偏抱团，两者都差则等待。
3. 大于2.3万亿但指数/趋势方向不支持，A同样不能判为成立；B须以自身正反馈成立，否则等待。
4. 关键数据不足为待判断。盘中看同时间放缩量；全天预测额只能标为估算，不与已完成日的真实量混用。

这是一版清楚的方向分流讨论基线，尚未启用。原MA5的2.1—2.3万亿对应100亿以下、小于2.1万亿对应50亿以下、大于2.3万亿不设上限，继续只描述个股容量资格。

“模式适用性”在页面写作“这条方向现在是否成立”，用证据解释，不生成未经验证的综合分数。缺少启用的兼容策略时，B可以有完整观察结论而没有执行策略候选；不强行套用MA5。

指数条件默认建议沿用MA5/10/20和现有四指数：相对昨收涨跌、站上几根均线、排列及斜率变化分别显示。指数的“较昨收上涨”与标准开收红K分开，不能把群体红K频率也静默改口径。

## 6. 先确定计算口径，再实现三类反馈

- 趋势：首板当日按截至当日的7日平均成交额分为 <50亿、50亿≤均额<100亿、≥100亿三档，沿用用户确认的容量标准，不另加市值口径。冻结档位后追踪，包含后来失败的样本，不以MA5筛选或事后走势筛赢家。
- 连板：至少3板的固定群体后续反馈，包含断板者。
- 抱团：按当时已选定的核心名单及生效日追踪，不能事后更换弱者来改善历史结果。

三组统一展示：**周期收益、红K频率、每日量价换手健康情况**。回撤、样本量和时间解释结果，不再以另一套收益比例重复定义正反馈。

红K按收盘高于开盘计算；单票看窗口内红K天数占比，群体看每日红K样本占比及相同窗口的逐日等权均值。形成观察样本的涨停当天不算后续反馈，停牌与缺行情不算有效交易日；有成交且开收相同的日子保留分母，一字涨停另标。周期收益与红K频率分开：低开收阳仍可能相对昨收下跌，不能用红K多直接宣称模式赚钱。

可参与性核心观察每日换手、量与额相对自身常态的变化，以及价格推进、回落、位置和阶段是否配合；分钟数据支持时进一步看承接与实际观察机会。换手率分母口径统一，盘中量与历史同时间比较。不存在通用的最佳换手率，也不能把爆量或缩量单独标为好坏。没有分钟数据仍可显示日线量价换手，但不冒充盘中可参与性已经确认。具体公式、边界和作者依据见七步链第5节。

已确认：大票按7日平均成交额的50/100亿分档；首板溢价固定为下一交易日开盘价/首板日收盘价−1，后续延续收益从该次日开盘起算。缺开盘行情不填0，统一价格调整口径；统计定义不等于实际成交或自动卖出。

仍需冻结的口径：收益与红K观察窗口、量价换手比较基准和阶段、板块核心比较依据。明确的数值条件交给确定规则；未量化部分允许人工判断并显示证据，不能由AI生成结论后伪装成已验证公式。

持有判断只比较次日之后的增量收益与其他同期限机会，首板溢价已经实现的部分不能重复充当续拿理由。用户已确认：超预期且原逻辑成立可以持有；符合预期默认离场，但可因没有更好的赚钱效应或趋势延续优势继续观察；不及预期/上游失效不开放上述例外。相关收益时点与已结束样本口径见量化补充稿第7节。

承接先计算VWAP上方停留、关键位收回、修复时间、回落/上攻量比和相对板块表现；超预期依据事前冻结范围与必要条件判断。5分钟粒度、15分钟窗口、分位数等仅为试算建议，未写入生产。

## 7. 业务分支验收清单

实现时以[完整业务树和CPO示例](vc_stock_decision_chain_spec_20260922.md)逐条对照，至少能讲清：

- 量足指数强时为何选A，以及为什么是这个板块。
- 量不足时走B，B中为何偏接力或抱团；两者都差时等待。
- 剑桥竞价正常时为何保留；剑桥弱而备选强时为何提升备选。
- 资金排名更高为何不足以单独决定换候选。
- 大盘仍支持但CPO走弱时回到板块比较；市场逻辑失效时重新比较方向。
- 观察核心可以不在MA5候选中；B无兼容策略时仍有可阅读的完整分析结论。
- 缺数据时说明缺什么，不伪造强弱或确认。
- 当日收盘进入当日盘后分析，并生成下一交易日预案。
- 红K频率高但周期收益差时明确显示背离；不将一字涨停的无阳线实体误判成亏钱。
- 可参与性展示逐日换手和量价依据，允许缺分钟数据而只能评价日线部分。
- 新人能看懂为什么选该板块和核心、当前准备捕捉哪段机会、何时观察什么；预期不兑现时明确等待或放弃本预案。
- 明确大盘 > 板块 > 个股；B的弱市适用性不被误写成所有模式必须指数上涨。
- 明确新候选“符合预期仍优先”与已持仓“符合预期默认次日离场”的差别。
- 没有更好的赚钱效应只对符合预期且原逻辑成立开放持有例外；不及预期或上游失效时不延期。
- 盘中新爆发能及时加入观察，记录发现时点及成员覆盖，不能越过模式与策略条件。

以上是分析功能验收，不是策略收益验证，也不包含交易台账或复盘反馈建设。本轮产出仅为修订文档和作者回复证据。
