# 题材复盘关注排序与封板样本修订 · 2026-09-15

题材默认展示要保留近期主线的分歧与衰退过程，不能每天等同于涨幅榜。此次未加入指定题材、股票或日期的置顶名单，也未按预期结果拟合权重。

## 排序与口径

- 仍用近7个交易日至少一只3板、两只不同个股2板为准入门槛。今日与昨日均无涨停不再直接删除，继续按7日门槛自然退出。
- 新生成题材成分时直接扫描可读取的概念和细分行业，避免当日/3日指数涨幅预筛漏掉分歧中的主线。历史成分重建标识保持原样。
- 在近7日仍活跃、本轮至少2板的成员中，选取最近最多20个交易日的启动后保留涨幅最高者作为关注核心。未满20日按实际启动后天数展示，超过20日截取最近20日，不比较无限期累计涨幅。不是统一20日收益率：不同启动日观察天数不同。
- 相同核心跨多个视角时，优先展示活跃成分占比较高的视角；原标签及其真实成分仍可展开。另沿用至少3只活跃成员、75%重叠的折叠规则。折叠只减少重复展示，不认证相同催化。
- 默认顺序按核心保留涨幅、核心活跃天数、7日二板以上家数、今日强度依次比较。没有人为合成加权分。今日强度四项等权百分位保持独立；资金承接与前后排反馈不被排序改写。
- 页面显示核心、观察天数、保留涨幅、回撤及未复权标识。靠前只是值得复盘，不能等同于买入信号。
- 对旧快照可按已归档核心候选刷新显示顺序，并按需加载新默认前三项的完整成员。完整重算从全部活跃候选识别关注核心。

这是一版待验证的复盘排序规则：单个核心仍可能代表多个不同催化，活跃密度也不能完全证明题材归属。后续在选股策略聊天继续设计环境、板型、买点与退出，不能把本次符合9月15日观察的结果当作策略回测结论。
