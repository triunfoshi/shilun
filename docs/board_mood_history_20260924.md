## 修复内容

统一分类后，历史情绪补算仍调用不带日期的股票分类函数，导致任务中断；旧情绪归档又因引擎版本过期被过滤。即使次日收益齐全，也只能显示“环境未覆盖”。

- 补算逐日传入历史日期，读取该日统一行业分类，使用原 P2 情绪引擎。未调整情绪权重、阈值或强／中／弱映射。
- 同版本的待补齐记录仍会重试。保存缺少的输入、价格覆盖、昨日反馈覆盖等诊断，缺失不计零、不划入弱情绪。
- 有效的当前 P2 快照优先；不完整的快照不会覆盖已补好的归档或清空其缺口原因。P2 与打板效应共用读取函数。
- 按名单形成日归组：例如9月23日的次日反馈，使用9月22日收盘情绪。20日、30日窗口不重算分位或改变同一天的标签。
- 缺少行业分类的股票不会被误认为集中在一个名叫“分类待补齐”的行业。
- 每组显示环境归组覆盖；页面底部“情绪日期与缺口”可展开反馈日、名单日、情绪、分组、得分和缺失原因。

原“刷新统计”流程已经调用此补算函数，本次修复后继续复用。独立修复命令：

```sh
./.venv312/bin/python -u -m shilun.jobs.market_mood_backfill_job --date 2026-09-23 --days 31
```
