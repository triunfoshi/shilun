# VC-Astock：本机后台连接 ECS 数据库

本流程仅迁移 MongoDB 存储，后台程序仍运行在 Mac。不要把 MongoDB 的 27017 端口开放到公网。

## 已准备的连接

- ECS：47.110.33.132，MongoDB 仅监听服务器的 `127.0.0.1:27017`。
- Mac：`127.0.0.1:27018` 通过 SSH 转发到 ECS MongoDB。
- 专用登录启动项：`cn.shilun.mongo-tunnel`。Mac 用户登录后自动连接，SSH 退出后重试；网络恢复后可以重新连接。Mac 关机、休眠、断网期间后台无法使用云端数据库。
- 隧道模板：`deploy/cn.shilun.mongo-tunnel.plist`。此模板针对当前 Mac 的路径，不适合直接复制到另一台电脑。
- 隧道日志：`runtime/mongo-tunnel.log`。不需要一直打开手动 SSH 窗口。

## 执行切换

关闭后台页面、手动采集程序及应用启动器。五个采集启动项需继续保持未加载状态，不要在切换过程中打开应用图标（启动器可能重新启用采集）。

在 Mac 终端执行以下一整行，不要在 ECS 终端执行：

```sh
/Users/shibicheng/shilun_standalone/.venv312/bin/python /Users/shibicheng/shilun_standalone/scripts/configure_ecs_mongo.py
```

输入 `YES` 确认，然后在隐藏提示中输入云端 **shilun_app 的数据库密码**，不是 SSH 密码，也不是管理员密码。不要把密码、`.env`、配置备份或完整连接字符串发到聊天或提交到 Git。

工具按以下顺序操作：

1. 检查原连接、启动配置和采集任务；验证云端账号可以连接。
2. 备份 `.env` 到已忽略的 `runtime/mongo-cutover-*/before.env`。备份目录仅本人可访问，备份文件仅本人可读写。
3. 暂停当前后台，逐集合比对数据量、内容校验值、索引和集合配置。内容校验会短暂阻塞数据库写入；请预留几分钟。使用 MongoDB 的 [dbHash 命令](https://www.mongodb.com/docs/manual/reference/command/dbHash/)，不下载或上传完整文档。
4. 比对通过才修改 `.env` 中的 `SHILUN_MONGO_URI` 和 `SHILUN_MONGO_DB`，其他配置不变。密码中的特殊字符自动编码。
5. 使用原启动配置重新启动后台，检查 `/readyz`。不启用采集任务，不删除本机旧库。

## 失败与回退边界

- 密码或隧道验证失败：不暂停后台、不修改配置。
- 数据不一致：不修改配置，重新启动原后台；保留两份数据库，先检查差异，不要用 `--drop` 强行重导。
- 写配置或启动新后台时失败：停止自动回退，打印已保存的备份位置；需要人工确认配置和进程状态。云端可能已有新写入，不能直接切回旧库。
- 中途退出后不要盲目重复操作；先根据提示确认后台状态。已经切换过的配置会被工具拒绝再次覆盖。
- 比对依赖所有外部写入者均已暂停。工具核对前后再次检查内容，但这不是跨两台服务器的事务，也不能替代停写窗口。

## 切换后的验收

看到“切换成功”后，再验证后台实际连接到了 `127.0.0.1:27018`，检查持仓、行情和复盘页面。确认云端读写正常后再恢复采集任务。

本机旧库和导出归档继续保留。ECS 自动备份、异机备份、云盘快照及磁盘释放策略仍需另外配置；SSH 自动重连不等于数据库备份。
