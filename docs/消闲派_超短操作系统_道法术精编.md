## 结论先行

消闲派并非一个单一的“打板选手”。他可被复原为一套：

> **以市场赚钱/亏钱效应为总开关，以主流题材和相对强度为选股过滤，以预期差和隔日溢价为交易锚，以动态仓位与快速纠错实现复利的情绪反馈型超短系统。**

他的常态执行以首板为主，但并不排斥半路、低吸、回封或高位接力；差别只在于市场状态是否允许、题材是否主流、标的是否前排、以及资金是否还能看到次日溢价。

```text
市场赚钱/亏钱效应
        ↓
题材主线与情绪空间
        ↓
龙头 / 前排 / 相对强标的
        ↓
竞价与盘中预期差确认
        ↓
半路、首封、回封或低吸等合适的切入方式
        ↓
按隔日溢价与结构是否兑现处理持仓
        ↓
仓位随环境、确定性和当日反馈动态收放
```

## 一、道：他到底相信什么

### 1. 市场不是图形集合，而是赚钱与亏钱效应的循环

| 日期 | 原话短摘 | 可迁移的含义 |
| --- | --- | --- |
| 2018-01-25 | “市场一直都是处于一个赚钱效应和亏钱效应的循环之中。” | 不把某一日盈亏当成常态，交易前先定位当前正处于扩张、分歧、退潮还是修复。 |
| 2018-01-25 | “赚钱效应时多赚点，是亏钱效应时少亏点。” | 复利的关键不是每笔都赢，而是进攻和防守随环境非对称配置。 |
| 2018-06-19 | “不管打什么板打的都是市场情绪，而不是简简单单的一个图形。” | 打板、低吸、回封只是表达方式；情绪和资金反馈才是上层原因。 |
| 2018-05-29 | “相同的图形不同的情绪结果是完全不同的。” | 任何形态都必须回到当时的指数、题材、前排反馈和市场位置中解释。 |
| 2018-01-22 | “打板的亏完亏接力的，接力的亏完亏低吸的。” | 风险会沿交易生态传导；不能看到某种打法赚钱，就忽略上游已经发生的亏钱效应。 |

| --- | --- | --- |
| 2017-12-27 | “完全跟随市场，及时止损，仓位控制，做龙头股之类的。” | 系统总纲是跟随、纠错、仓控和核心股，并非寻找神秘买点。 |
| 2018-01-05 | “尽量买主线。” | 题材处于市场主线，比孤立的个股故事更重要。 |
| 2018-01-05 | “主线的龙二龙三可能比非主线的龙头肉要多。” | 板块地位有时高于单票绝对排名；先判断是不是主线，再比较个股排序。 |
| 2017-12-26 | “越到行情后期越要往龙头上面转移。” | 后期资金会向辨识度集中，后排的隔日溢价和流动性更脆弱。 |
| 2017-12-29 | “不要急于买跟风，钱留着第二天上龙头更稳妥。” | 踏空不是错误；为了参与感降低标的质量，才容易造成大回撤。 |
| 2018-01-09 | “永远只做多头排列的票和上升趋势的票。” | 默认偏好顺势；基本面故事不能自动覆盖弱趋势。 |

### 3. 预判是起点，盘面跟随才是交易本身

| 2018-01-07 | “关键是要看超预期还是低于预期。” | 高开、低开、炸板本身没有固定意义，必须与先验预期相比。 |
| 2018-02-04 | “超预期了是否跟进，低于预期是否出掉。” | 盘中操作的核心是持续更新预期，而非守住事先判断。 |
| 2018-03-17 | “低于预期优先处理，超预期的留着看看。” | 持仓管理以逻辑是否增强或减弱为锚，而不是以成本线或浮盈回撤为锚。 |

### 4. 回撤、纪律和适配性比单笔暴利重要

| 日期 | 原话短摘 | 可迁移的含义 |
| --- | --- | --- |

| 2018-06-02 | “只根据市场的赚钱效应和亏钱效应来决定仓位的增减。” | 仓位是环境的函数，不是固定的满仓、半仓或主观信念。 |
| 2018-07-04 | “出手成功率决定后面是否继续开仓。” | 当日早期交易反馈也是风险信号；连续失手应压制后续冲动。 |
| 2018-12-08 | “把一种模式练到极致为好。” | 普通交易者的优势来自深度专精，而不是频繁追逐最新的赚钱手法。 |
| 2019-07-08 | “亏钱就换模式是大忌吧。” | 先区分环境逆风、执行变形和体系失效，不用短期亏损否定熟悉的系统。 |
| 2020-02-01 | “不能主动适应市场的话被淘汰的很快。” | 专精不等于教条；底层原则可延续，具体阈值和手法必须随市场变化校准。 |

## 二、法：他如何把市场观变成可重复的判断框架

### 1. 先判市场状态，再谈个股

他判断环境时，反复看的是市场的实际反馈：昨日涨停股表现、连板数量、冲高回落、开板/炸板、接力亏钱效应、指数与板块强弱，而不是只盯某一条均线或某个技术指标。

| 状态 | 派神式判断 | 对应动作 |
| --- | --- | --- |
| 赚钱效应扩张 | 昨日强股有溢价、连板有高度、主线扩散、前排不轻易亏钱。 | 提高进攻仓位；首板、接力和主线前排都有参与空间。 |
| 分歧/转换 | 高标或板块反馈开始分化，仍有核心股保持强度。 | 缩小仓位，优先核心或换手确认；不把弱跟风当低价替代。 |
| 亏钱效应/退潮 | 昨日强股负反馈、炸板/冲高回落扩散、接力溢价消失。 | 降仓、空仓或只以小仓观察最强相对强者；回避高位接力和后排。 |
| 恐慌后的修复 | 一致性杀跌，但有标的抗跌、率先修复，且恐慌开始缓和。 | 研究抗跌核心、被动下跌后的反抽或修复，而非无差别抄底。 |
| 逼空/情绪高潮 | 龙头不断打开空间，题材有明确示范效应，接力仍给正反馈。 | 可提高接力比重，但必须警惕“最危险的是一致后的加速”。 |

几个关键原话：

- 2018-06-19：“我一般通过涨跌幅榜，昨日涨停股表现，接力亏钱效应来判断。”
- 2018-01-04：“赚钱效应足时多追高打板，有了亏钱效应时控制仓位，谨慎出手。”
- 2019-01-18：“该在情绪高潮期接力，而不该在这种情绪退潮期去做接力。”
- 2018-02-01：“尽量空仓保平安的好。硬要操作的话还是找强势股做。”

### 2. 题材先于形态，板块先于单票

他选择“主线”的标准不是新闻标题，而是四件事同时出现：**联动、人气、容量、走势**。这也是他为什么会反复要求看板块内其他股票、前排溢价和补涨反馈。

| 日期 | 原话短摘 | 方法含义 |
| --- | --- | --- |
| 2016-05-31 | “这板块联动性好，人气好，又能容下大资金，技术面也完美。” | 主线必须有可见的群体性和容量，不是单票异动。 |
| 2018-01-05 | “判断下板块的历史表现情况，股性呆滞的少碰。” | 题材和股性共同决定资金是否愿意持续参与。 |
| 2019-03-18 | “资金才可能继续去挖掘补涨股。” | 补涨不是题材联想，而要由已有补涨的赚钱效应验证。 |
| 2020-02-20 | “特斯拉偏题材炒作，科技重在趋势。” | 题材情绪股和机构趋势股要用不同的持有周期、买点与预期。 |

### 3. 选股的优先级：主线中的前排、强度与相对位置

他的选择链条大致如下：

```text
市场允许出手？
  └─ 是 → 有主线/持续性吗？
            └─ 是 → 谁是龙头、前排、率先转强或最抗跌者？
                       └─ 有股性、趋势、量能和板块联动吗？
                                  └─ 再判断具体买点。
```

这解释了几个表面上看似矛盾的观点：

- **首板优先，但不迷信首板。** 2019-02-15：“首板对收益提升最快的肯定是打到主流板块里的龙头。”
- **后排不是永远不能做。** 只有强势扩散、主线高潮且前排仍有溢价时，才有后排套利空间；分歧和退潮中，后排先被淘汰。
- **低吸不是抄弱。** 2018-11-29：“大盘大跌时找抗跌的低吸。”他的低吸对象是恐慌中相对强者。
- **接力不是常态。** 2019-10-17：“首板为主，行情好时会做连板。”但逼空、连板高度持续扩张时，他会提高接力比重。

### 4. 交易价值锚：能否获得隔日溢价

他的超短大部分是隔日交易。2018-06-14，他明确说“我都是隔日为主”，并补充自己买入的逻辑“看不了那么远”。因此，首板、回封和尾盘套利的共同问题不是“今天能否封住”，而是：

> **明天为什么会有人接？预期如何继续发酵？如果不发酵，退出是否有流动性？**

这也是他看回封和烂板的标准：

- 2018-04-20：“封板的资金要能看到第二天的溢价才会去回封这种烂板吧。”
- 2018-04-22：“不是炸板后第二天高开就一定是超预期的。”
- 2019-09-12：“首板容不得你幻想，首板是看不出来能不能成为大牛股的。”

## 三、术：盘前到次日的具体执行流程

### 1. 收盘后：复盘建立候选池，而不是预定买入

复盘的目的，是建立“待涨逻辑”和可能的次日预期，而不是选出一只必须买的股票。

- 2018-05-29：“做短线的怎么可能不复盘呢。”
- 2018-07-03：“涨跌停股，会顺着往下多翻翻，自选股。再看看别人的复盘。”
- 2019-02-13：“顺着涨幅和跌幅榜多往下翻很多。”

复盘检查清单：

1. 昨日涨停、连板、高标、炸板和冲高回落的反馈；
2. 主线及其前排/后排、是否扩散或开始掉队；
3. 当天涨跌幅榜、潜在新题材、个股异动的逻辑与股性；
4. 持仓在次日应有的预期：什么叫超预期、什么叫低于预期；
5. 连板候选以盘前预案为主，首板候选保留盘中发现的空间。

### 2. 开盘与竞价：先处理风险仓，再看全市场反馈

| 日期 | 原话短摘 | 执行含义 |
| --- | --- | --- |
| 2018-01-07 | “先处理弱的，超预期的会先留着看看。” | 开盘第一任务是管理隔夜风险；强者可以获得观察时间。 |
| 2018-01-09 | “首先关注你的目标股竞价。” | 先看持仓与预案，再看昨日强股和全市场的竞价反馈。 |
| 2018-01-17 | “做首板以临盘选为主，打连板以复盘选为主。” | 首板看实时强度和资金选择；连板依赖预案和竞价确认。 |
| 2019-01-17 | “这种竞价太弱的票我都会趁流动性好时多卖点。” | 明显低于预期时，优先在开盘的流动性窗口降风险。 |

### 3. 买入：让确定性决定手法，而非让手法决定买入

| 场景 | 派神的操作偏好 | 证据与边界 |
| --- | --- | --- |
| 首板 | 以盘中发现为主，重点看主线、前排、股性、分时强度和板块联动。 | “首板以临盘选为主”。弱市首板更要求题材和板块逻辑。 |
| 半路 | 当分时、板块和预期已能显著提高上板概率时，可提前试仓。 | 2018-01-03：“半路就能看出要板自然半路就买了。” |
| 板上确认 | 当涨停才形成足够确认时再买，避免用主观想象替代确认。 | 同一条原话的后半句：“涨停才能确认那就打板买。” |
| 加仓 | 有时半路先建小仓，封板后再加；高位更偏好换手、烂板或回封后的确认。 | 2018-01-04：“半路会买点，涨停再加。” |
| 回封/烂板 | 不看“炸了又封”这个表象，而看题材、股性、为什么开、如何回、换手和抛压。 | 2018-01-18：“看题材，看股性，看为什么而烂。” |
| 恐慌低吸 | 指数或板块一致下跌时，找抗跌或最早修复的相对强者。 | 不是无差别抄底；弱势票仍应回避。 |

几个高频的盘口限制条件：

- 2018-01-12：“尽量少打直线拉板的，分时上一个平台接一个平台拉上去的是最安全的。”
- 2018-01-12：“出现这么巨额卖单后封单都会比较犹豫，没必要扫，该排下的。”
- 2018-06-08：“这种氛围太早的一封没必要上。”
- 同日：“打烂板或者类似超频三这样大幅换手后的封板。”
- 2019-04-20：“见顶后的调整期的直线拉板极少有成功的。”

这些不是机械条件，而是同一个原则的不同表现：**需要看到抛压被消化、资金愿意继续承接，且市场仍允许隔日溢价。**

### 4. 持有与卖出：由“预期是否兑现”决定，不由固定点数决定

这是他最容易被误读的部分。他不是“死扛”，也不是固定止损；他倾向把卖点放在预期、环境和相对强弱的联合判断上。

| 日期 | 原话短摘 | 执行含义 |
| --- | --- | --- |
| 2018-01-08 | “没有兑现就拿着，兑现了或者低于自己预期就走。” | 先定义买入后应发生什么；兑现后可收割，落空后快速纠错。 |
| 2018-01-08 | “跌破分时不拉回是走弱的标志，但也要区分是主动性跌破还是被动跌破。” | 区分个股自身弱，还是被指数/板块拖累，不能一刀切。 |
| 2019-04-13 | “趋势是多头排列的，股价阶段新高的，开盘没溢价的话我会愿意多等等。” | 高质量趋势股不能仅因没有次日溢价自动卖出。 |
| 2019-04-14 | “随盘面强弱止损，没有刚性止损点。” | 止损必须动态地参考盘面、题材、承接和预期差。 |
| 2017-12-29 | “不要怕卖飞，真涨停了再买回来就是了。” | 防守式卖出可以被后续确认的买点修正，不要为卖最高点牺牲纪律。 |

### 5. 仓位：用风险暴露表达确定性

他的仓位不是一个常数。它同时受三个层级影响：市场赚钱/亏钱效应、单票与题材的确定性、以及当天已出手交易的反馈。

```text
市场转弱 / 接力负反馈扩大 → 降低总仓或停止新增
市场中性但有强核心         → 小仓观察或只做核心
主线扩散且前排正反馈       → 提高总仓，允许更多进攻手法
个股/题材不够确定          → 用小仓试错，不以主观信念补仓
前一两次出手失败           → 降低后续交易频率与仓位
```

原话证据：

- 2017-12-26：“主要根据盘面的赚钱效应和亏钱效应来控制仓位。”
- 2017-12-26：“前一两次出手失败后也会约束自己不再开仓。”
- 2019-05-06：“把握不是那么大的票以练手感为主，买的很少。”
- 2018-01-09：“我心中的理想状态是这个资金量满仓不超过五个股票。”

最后一条是他的个人风险偏好和资金体量下的例子，不应被解释成通用的持仓数量规则。

## 四、从“道—法—术”压缩出的完整操作系统

### 系统名称

**情绪反馈驱动的主线隔日交易系统。**

### 核心变量

| 层级 | 核心问题 | 典型可观察事实 |
| --- | --- | --- |
| 市场 | 今天应进攻还是防守？ | 昨日涨停表现、连板高度、接力溢价、炸板、冲高回落、涨跌幅榜。 |
| 题材 | 资金在做什么，是否有持续性？ | 板块联动、前排高度、容量、人气、扩散和补涨反馈。 |
| 个股 | 谁是最值得参与的表达？ | 龙头/前排、相对强度、股性、多头趋势、首封时间、换手和承接。 |
| 时点 | 什么时候确认度最高？ | 竞价是否超预期、分时转强、封板、开板后的承接和回封速度。 |
| 风控 | 错了该如何退出，正确时如何持有？ | 是否低于预期、是否主动走弱、板块与指数是否转弱、隔日溢价是否仍在。 |

### 每日决策链

```text
D-1 收盘复盘
  └─ 识别赚钱/亏钱效应、主线、候选前排和持仓次日预期

D 竞价与开盘
  └─ 先处理低于预期的持仓
  └─ 用昨日强股与主线竞价校正环境判断

D 盘中选择
  └─ 环境允许？
       ├─ 否：降低仓位，或仅观察相对强者
       └─ 是：寻找主线前排、龙头、趋势或抗跌修复标的
                 └─ 确定性在哪个时点出现？半路 / 首封 / 回封 / 低吸

D+1 处理
  └─ 超预期：保留观察或加仓
  └─ 符合预期：按隔日套利计划兑现或择强持有
  └─ 低于预期：利用开盘流动性优先处理

全过程
  └─ 用仓位表达不确定性；连续失手则收缩，而不是报复性交易
```

## 五、看似矛盾、实则有状态边界的观点

| 表面矛盾 | 正确理解 |
| --- | --- |
| “首板为主” vs. “行情好会做连板” | 首板是常态优势；当市场逼空、连板高度持续、接力给正反馈时，系统扩展至高位接力。 |
| “永远只做上升趋势” vs. “大跌时找抗跌低吸” | 后者不是抄弱，而是在恐慌中找相对强、逻辑未坏、最早修复的标的。 |
| “止损坚决” vs. “没有刚性止损点” | 他强调执行的果断性，但阈值由预期、市场、板块和承接决定，不是统一亏损百分比。 |
| “不追后排” vs. “行情火热时可做龙二龙三” | 后排只在主线正反馈、扩散期和流动性充足时有价值；退潮或分歧期，后排通常先亏钱。 |
| “模式专精” vs. “主动适应市场” | 不随短期盈亏乱换手法，但允许根据市场阶段在自己的能力圈内调整首板、接力、低吸等权重。 |

## 六、最容易被机械误用的原话

这些句子必须放回当时的市场状态，不能直接升级为石论的自动规则：

1. **“下跌趋势一旦形成任何利好都是给你跑路的机会。”**
   - 来自极弱行情经验，不适用于所有指数调整、错杀修复或结构性行情。
2. **“烂板我也经常买。”**
   - 重点在后半句：看题材、股性、为什么开板、换手和回封承接。
3. **“分时上一个平台接一个平台拉上去的是最安全的。”**
   - 是个人首板偏好，不足以替代市场位置、题材地位和隔日溢价判断。
4. **“大盘大跌时找抗跌的低吸。”**
   - 说的是筛选最强者，不是号召在大跌中无差别低吸。
5. **“尾盘打些跟风去套利。”**
   - 原始前提是情绪转好、新题材爆发、且有可用仓位；不是固定尾盘买入策略。
6. **“妖股是非常安全的。”**
   - 属于高度行情下的个人经验表达，不能作为高位接力的风控结论。

## 七、对石论的启示：可研究，不应直接硬编码

派神体系最适合被拆成“事实—判断—动作”三层：

| 层级 | 石论应记录的事实 | 可以研究的判断 |
| --- | --- | --- |
| 市场情绪 | 昨日涨停/连板收益、炸板率、跌停扩散、接力溢价、涨跌幅榜。 | 赚钱效应、分歧、退潮、修复、逼空。 |
| 板块结构 | 板块涨幅、广度、成交额、前排/后排表现、核心股反馈。 | 是否主线、是否扩散、是否只有抢先手而无引爆。 |
| 个股强度 | 竞价、首封/末封、开板次数、回封速度、换手、相对强度。 | 龙头候选、回封质量、超预期/低于预期。 |
| 执行与风控 | 入场理由、预期、失效条件、总仓/单票仓、当日先前交易结果。 | 是否加仓、持有、兑现、止损或停止新增。 |

在有足够样本和无时间穿越验证前，尤其不能把“情绪”“超预期”“烂板回封”和“高标”直接写成固定买卖信号。它们应先成为可回放、可证伪、可分市场状态统计的候选规则。
