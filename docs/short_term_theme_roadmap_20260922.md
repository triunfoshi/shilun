# 短线主线筛选与涨停复盘：分步修改路径

更新：2026-09-23。统一分类、独立核心资格已落地；本轮拆分了“核心资格”和“强势股复盘”，P2 已接入真实核心资格并取消成分 50 家上限。第三步归因与扩散验收已接入，第四步跨日周期及四页共用归档已接入；退出阈值与更早医药样本仍待业务验收。详见 [本轮交付](strength_review_20260922.md)。

## 一、目标与规则边界

短线周期观察从符合资格的核心出发，经题材归因、扩散与延续筛选，收敛到最多三个方向。重点解释为什么入选、为什么其他方向落选、阶段如何变化。

### 已明确的用户要求

- 强势股按自选区间涨幅排名，默认近 20 个交易日前 50 只；不设五板门槛。以下三连板和十日五板条件只用于核心资格。

- 周期内重点观察约 2—3 个方向；不合格不凑数。
- 全站题材、概念和行业板块共用一个分类来源、一个权威目录和一套成分映射。P2、板块研究、选品研究、涨停聚焦及个股分析不各自选择或拼接分类体系。
- 核心必须同时满足：新连板段至少三连板，且从该段首板起十个交易日内累计至少五次收盘涨停。走势周期可以延续，各新连板段独立认证；仅三板、四板或没有三连板的十天五板均不入选核心。
- 保留走势周期及从走势首板起算的累计涨幅，不因新连板段重新认证而清零。资格段首板与走势首板分别记录；二板情况用于题材阶段判断，不是替代核心硬门槛的入选通道。
- 核心收盘回撤阈值先固定为 15%，基准为本走势周期截至复盘日的最高收盘价；跨除权统一价格尺度。达到阈值触发转弱预警，结合固定后排反馈判断退潮，不将其单独当作自动退出或走势重置条件。新连板段认证不重置走势收盘峰值。
- “周期待确认”必须就地反馈具体原因、证据缺口与下一步处理，并能追踪是否已修复；不能以同一文案长期掩盖数据、关联或规则问题。
- 可以没有综合总分，但必须有筛选、比较、淘汰机制。
- 先识别核心，再检查与其相关、真正活跃发酵的题材。
- 涨停聚焦增加“涨停复盘”，用于盘后多日对照；现有连板天梯改为盘中检测，移除次日概率，保留实际晋级统计。
- 多选高亮累加保留；个股跨日匹配；题材新增独立颜色；支持日期、题材、行情联动及双击行情图进入个股分析。
- 排序支持从多个指标中选一个，并切换升降序。

### 核心口径：用户已确定的硬条件

- 走势周期与资格窗口使用两个锚点：走势首板保留累计表现，新连板段首板开启独立的十日资格窗口。三连板和五次涨停必须在同一个资格窗口内成立，不把资格段之前的涨停或旧走势周期的板数拼进来。十天解释为交易所十个交易日，资格段首板当日为第 1 日；停牌不延长交易日窗口，缺数据也不跳日。
- 新连板段指经完整交易日证据确认，非涨停之后重新开始的连续收盘涨停段；第三个连续涨停形成后可确认其三连板条件，锚点仍是该段第一板。段内不能每天移动起点，也不能看到第五板后挑一个有利窗口。缺数据或停牌不能直接当作已知非涨停来制造新段。
- 资格窗口内允许断板后反包，累计板数按日期去重；新段的独立认证不删除旧段的认证记录。多个资格窗口均通过时，当日按股票代码去重，不重复充当多个独立核心或跟随股。
- 截至资格形成日，两项条件须在上述窗口内同时成立；不能通过十日之后形成的三连板补足早期累计五板。
- 连续五板自然达标；非连续的十天五板须另有至少三连板才能达标，二者展示时分别注明。
- 走势累计涨幅起点采用走势首板前的有效昨收，包含走势首板当日收益；另可展示资格段涨幅，起点为资格段首板前有效昨收。两者分别按每日有效昨收收益连乘，跨除权统一价格口径；起点或价格缺失时标记无法核验，不混用起点。
- 最早满足两个条件的交易日为资格形成日，不能回填到首板日；资格形成后的周期延续、退潮和退出另外管理，不因滚动窗口移出第五个板机械丢失历史资格。
- 走势首板、资格段首板及各自边界必须留证；边界未闭合时，不可任意选择有利的十日窗口，不能宣称已完整核验该段资格。

### 仍需回放校准的题材与周期参数

- 扩散初稿：近三个交易日，至少两只非核心个股涨停，相关涨停活动跨越至少两个交易日。二板数量不作为额外硬门槛。
- 排序初稿：扩散延续、独立跟随与晋级、核心和固定前排反馈、核心高度与辨识度。具体比较字段须在第三步固定。
- 新的主线筛选路径以真实扩散与归因为依据，拟替代完整成分超过 50 家即排除的规则。其他策略可以有明确的样本筛选条件，但题材身份、分类来源、成分和周期归属必须全站一致。
- 两个核心条件为用户确定的产品规则，不参与“放宽到三板即可”的参数对照；扩散、退出和周期转换参数才是后续回放校准对象。它们不是蟹老板原有公式，也不是收益或可交易性验证结果。
