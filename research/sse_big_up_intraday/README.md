# 上证指数大阳日分时形态研究

主口径是“较前收涨幅不低于 1%，且收盘高于开盘”。分析脚本读取 KlineShare
上证指数日线和 1 分钟线，输出逐日指标、中位路径、四分位路径、阈值敏感性、
留一法稳健性和本地 Tushare 日线交叉核验结果。

运行：

```bash
./.venv312/bin/python research/sse_big_up_intraday/analyze.py --as-of 2026-09-05
```

分钟接口通常返回 09:31 至 14:59 共 239 个点。脚本只在全部 239 个连续竞价
分钟完整时纳入样本，并使用同源日线收盘价补上 15:00 锚点；不插补其他缺失
分钟。所有时间均按 `Asia/Shanghai` 解释。

本研究是描述性事件分析，不把三个月小样本直接解释为可交易的预测规律。
